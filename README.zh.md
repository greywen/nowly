# Nowly · 此刻，你的 Windows 个人工作桌面

[English](README.md) | 简体中文

为自己的这一天，留一张桌面。Nowly 把日程、任务、记录和时间放在可以自由组织的工作区里，面向在 Windows 上工作、学习和独立交付的人。可以像普通窗口一样使用，也可以放到桌面图标之后，通过 Nowly Bar 随时查看提醒、打开快捷工具。

## 桌面围绕你，而不是反过来

- **安排这一天：** 本地日程与提醒，按需连接 Google/Microsoft 日历或只读 ICS 订阅。
- **看清下一件事：** 用四象限区分紧急与重要，或用轻量看板、泳道和任务详情组织进度。
- **随手留下想法：** 便签记录，再按需用贴纸画布放文字和图片。
- **让时间看得见：** 添加「时间」查看世界时钟、设置本地时间闹钟、开始专注并查看统计；切换时钟/专注显示不会停止计时。
- **自己组织空间：** 六个内置模块按需添加，在 12×8 网格内摆放和缩放，调整密度、颜色、模糊程度与图标风格。
- **少一次切换：** Nowly Bar 提供提醒、截图、截图历史及可选 AI 助手；功能菜单显示/顺序与截图快捷键可设置。

工作时，把会议、下一步任务和随手记放在一起；学习时，把截止日期和专注时段放在眼前；自由职业时，让自己的交付看板和参考笔记常驻桌面。它是个人工作桌面，不是多人协作或跨设备云工作区。

## 先从简单的开始

1. 打开 Nowly，在 **编辑布局 → 添加模块** 中选择需要的模块；没有空位时先缩小或移除其它模块。
2. 写下一个日程、任务或便签，需要时再添加时间与贴纸。
3. 点击壁纸按钮把工作区放到桌面图标之后；双击壁纸或点击托盘图标回到前台。
4. 提醒需要 Nowly 持续运行，可以留在托盘；关闭窗口不是完全退出，结束进程请用托盘的 **退出 Nowly**。

时钟、闹钟、自动保存与重试、贴纸限制、截图保存位置、桌面模式及开发说明都在 [用户指南](docs/user-guide.zh.md)。

## 本地优先，连接边界说清楚

基础本地功能不要求 Nowly 账户。结构化记录使用本地 SQLite，附件、贴纸图片、截图及部分界面偏好使用其它本地存储。连接日历后会拉取并缓存外部事件，普通日历编辑器经授权可写入 Google/Microsoft。**本地优先不等于所有功能离线，也不等于没有同步。**

AI 是可选助手。配置自己的模型接口，再选择允许的日历、任务或外部日历上下文；请求会把输入、近期对话、时间信息与允许的查询结果发送给该接口。**外部日历权限包含 Google、Microsoft 和 ICS 缓存事件，即使模型来自另一家供应商。** AI 只提出本地日程/任务变更方案，明确确认后才执行，不能编辑外部日历。准确字段、凭据、联网与留存边界见 [隐私与数据](docs/privacy-and-data.zh.md)。

## 开发者入口

React + TypeScript + Vite、手写 CSS、Tauri 2/Rust，SQLite 配合独立本地资源文件；既有测试使用 Vitest、Playwright 与 Rust tests。Windows 开发需要 Node.js、Rust 及 Tauri 的 Windows 依赖。命令、目录结构与限定开发重置警告保留在 [指南的开发章节](docs/user-guide.zh.md#开发)。本文不是平台兼容性实测报告。
