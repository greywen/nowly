# Nowly · 此刻

**一块只回答一个问题的桌面面板：此刻，我该做什么？**

[English](./README.md) | 简体中文

Nowly 的中文名是「此刻」。它是一款面向 Windows 10/11 的本地优先（local-first）
专注面板。与其把一天拆散在日历应用、待办应用、看板和便签之间，Nowly 把今天的
日程、真正重要的任务和专注计时器，一起放在你本来就一直看着的地方 —— 桌面。

把它设为壁纸，它就融进背景：不用开窗口，不用切应用。抬眼一看，知道下一件事是
什么，然后开始专注。所有数据都保存在本机的 SQLite 数据库中。

## 为什么是「此刻」

- **一眼一个答案。** 今天的日程、当下该做的任务、这一轮专注剩余的时间，不点
  一下就能看见。
- **活在桌面上。** 壁纸模式把 Nowly 嵌到桌面图标之后，面板始终在，却从不挡路。
- **专注而非堆积。** 艾森豪威尔矩阵和专注计时器的目的，是把清单收敛到「此刻
  值得做的那一件」。
- **只属于你。** 无账号、无同步、无遥测，本地优先。

## 功能特性

- **月历** —— 创建带时间、颜色的日程，支持按天查看详情，让今天的安排始终在视野里。
- **艾森豪威尔矩阵** —— 按「紧急 / 重要」四象限整理任务，让「马上做」象限保持诚实。
- **专注计时器** —— 倒计时专注会话，支持无干扰全屏模式与会话统计。
- **看板** —— 可自定义泳道、卡片和字段，进行轻量级项目跟踪。
- **便签** —— 快速记录，并提供独立的管理器整理条目。
- **壁纸模式** —— 将 Nowly 嵌入桌面图标之后，支持任务栏感知定位，也可作为
  普通窗口运行。
- **灵活布局** —— 在 12×8 网格上自由摆放每个模块，可开关模块并自由调整大小。
- **个性化** —— 高斯模糊、全局取色器、日历格式、密度控制以及开机自启。
- **截图与截图历史** —— Nowly Bar 一键截图、可配置全局快捷键、统一 PNG 归档及 Bar 内展开的历史面板。
- **多语言** —— 支持英文与简体中文，启动时跟随系统语言。

## 使用说明

- 点击右上角按钮，将 Nowly 设为壁纸。
- 双击壁纸或点击托盘图标，返回前台窗口模式。
- 打开 **设置**，可控制壁纸关闭行为、开机自启、日历格式、密度以及模块可见性。
- 当启用壁纸偏好时，关闭前台窗口会恢复壁纸；否则窗口会隐藏到托盘。
- 托盘菜单中的 **退出 Nowly** 是唯一会终止进程的操作。

### 截图与截图历史

点击 **Nowly Bar 的 Logo** 展开功能菜单，选择 **截图、截图历史或 AI 助手**。在 **设置 → 通知 → Nowly Bar → 功能菜单** 中设置显示/隐藏和顺序；新安装及旧版升级默认显示三项。隐藏只影响菜单，不影响快捷键；允许全部隐藏，菜单会显示重新启用的设置说明。截图默认快捷键 **Ctrl+Alt+A**，截图历史默认 **Ctrl+Alt+H**；在 **设置 → 快捷键** 中修改。快捷键冲突会明确提示，不会阻止应用启动。

“保存”直接写入系统 **图片\Nowly\Screenshots**，不再弹出另存为。“复制图片并完成”也先保存最终 PNG，再写入图片剪贴板。只保存裁切、标注和马赛克后的最终结果；取消不产生记录。系统图片目录被重定向时，保存位置随系统设置变化。

截图历史直接从屏幕顶边的 Nowly Bar 动画展开，不再打开独立窗口。折叠 Bar 固定 **288 × 40px**，仅保留提醒/状态区和 Logo 入口；提醒、功能菜单、AI 和历史面板的展开宽度统一为 **432px**。使用历史快捷键前需启用 Nowly Bar。按 Esc、点击关闭键或面板外部即可收起；删除确认打开时 Esc 优先取消确认，再点 Logo 回到功能菜单。面板提供缩略图、复制图片、确认删除和打开文件夹。记录一直保留；确认删除同时删除本地 PNG 和缩略图缓存。不要将此目录当作自动清理的临时文件夹。

归档失败时保留截图编辑内容，不执行复制；图片已保存但剪贴板写入失败时可重试，同一最终图片不会重复归档。历史复制不增加新记录。缩略图缓存可重建，原图不会存入 SQLite；原始整屏底图只用于当前截图会话。

浏览器开发模式仅用于验证界面，不能操作真实截图文件或系统全局快捷键；完整功能需在 Windows 桌面应用中运行。

## 技术栈

- **前端** —— React + TypeScript，基于 Vite 构建，样式为手写 CSS，全部取值来自 `design.md`
  的 Token，不使用工具类或 CSS-in-JS 框架。
- **桌面外壳** —— Tauri 2，后端使用 Rust。
- **存储** —— 通过 `rusqlite`（bundled）使用本地 SQLite。
- **图标** —— [Solar 图标集](https://www.figma.com/community/file/1166831539721848736)，
  作者 480 Design，许可协议 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。
  字形通过统一适配层（`src/components/icons.tsx`）本地引入，用 `npm run icons` 重新生成；
  双色 / 实心 / 线性三种风格可在设置中切换。
- **测试** —— Vitest 负责单元/组件测试，Playwright 负责端到端测试，
  `cargo test` 负责 Rust 层测试。

## 开发

环境要求：Node.js、Rust 工具链，以及 Windows 下的 Tauri 依赖。

```bash
npm install                                        # 安装依赖
npm run dev                                         # Vite 开发服务器（127.0.0.1:1420）
npm test                                            # Vitest 单元/组件测试
npm run build                                       # tsc + vite build
npx playwright test                                 # 端到端测试
cargo test --manifest-path src-tauri/Cargo.toml     # Rust 测试
npm run tauri build                                 # 构建 Windows 可执行文件
```
