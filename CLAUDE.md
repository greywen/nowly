## Design System

Before designing, implementing, or modifying any page or UI component, read the root-level `design.md` completely and follow it strictly. `design.md` is the project's authoritative visual specification and overrides older design tokens or prototype styling.

## Git Commit Format

All commit messages shall follow the unified format below:

```text
<type>: <short description>
```

Examples:

```text
feature: add task creation dialog
fix: resolve page scrolling issue
docs: update project run instructions
refactor: simplify task state management
test: add task creation tests
chore: update dependencies
```
