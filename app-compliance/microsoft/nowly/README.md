# Microsoft / Nowly 材料预留

这里预留 Microsoft Calendar 的合规材料边界。当前只建立目录和配置契约，不把它当作已经可以提交 Microsoft 审核的完整材料。

Nowly 当前代码使用的 Microsoft scope 是：

```text
openid
email
offline_access
https://graph.microsoft.com/Calendars.ReadWrite
```

在补充完整材料前，需要确认 Microsoft Entra 应用类型、租户范围、应用显示名称、支持邮箱、隐私政策 URL、服务条款 URL、数据删除流程和最终权限。不要直接把 Google 的审核文字复制到 Microsoft 申请中。
