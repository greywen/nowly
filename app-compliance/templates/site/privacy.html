3. Protection of sensitive Google user data

{{productName}} uses the OAuth 2.0 Authorization Code flow with PKCE and a random state value. The authorization response is returned only to a temporary loopback listener on the user’s device.

Authorization, token exchange, and Google Calendar API requests are transmitted over HTTPS (TLS) and are restricted to Google’s authorization, token, identity, and Calendar API endpoints.

{{tokenStorageDescriptionEn}} Access and refresh tokens are encrypted before they are written to the local database, are tied to the current Windows user account, and are decrypted only by the application backend when an authorized Google API request is required. OAuth tokens are not intentionally logged, are not exposed to the application interface, and are not sent to a developer-operated server.

{{calendarStorageDescriptionEn}} The local calendar cache is available only through the user’s Windows account and Nowly application functions. Users should protect their Windows account, keep the operating system and Nowly updated, and disconnect the account if a device is lost or shared.

4. Sharing, advertising, analytics, and Limited Use

{{thirdPartyDataStatementEn}}

Google user data is not used to train, develop, or improve generalized artificial intelligence or machine learning models.

{{analyticsStatementEn}}

Nowly’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Optional networking and local-first storage

Nowly is your personal workspace for Windows. Local-first does not mean every feature is offline. In addition to authorized calendar synchronization, the optional AI assistant sends your input, conversation history and permission-filtered context to the model service you configure. When external-calendar reading is enabled, context may include cached Google, Microsoft or ICS events. AI access to external events is read-only and cannot modify remote calendars. Do not send sensitive information without authorization, and check your provider's retention policy.

Google user data must not be used to train, develop or improve general-purpose models; users should select provider configurations consistent with Limited Use requirements. Nowly performs update checks against GitHub release information. The website has no analytics scripts, but its hosting service may generate ordinary access logs. Local storage includes databases, attachment files and screenshot PNG files. Native desktop integrations and optional external services are not executed by this public website.

5. Retention, disconnection, and deletion

You can disconnect a connected account in {{productName}}. Disconnecting removes the locally stored OAuth tokens, account connection, subscription settings, and associated local event cache. You may also send a deletion request to {{dataDeletionEmail}}.

Disconnecting Nowly does not automatically delete original data in your {{providerLabel}} account. You remain in control of that data through Google.
