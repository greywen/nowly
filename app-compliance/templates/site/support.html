Connect {{providerLabel}}

In Nowly calendar settings, select Connect account, complete login and consent in your browser, then return to Nowly and choose the calendars to display. End users do not provide a Client ID.

Permissions

The permissions shown during consent are determined by the current application version. See the Privacy Policy for details. Calendar access is used only to display authorized calendars and perform calendar operations explicitly initiated by the user in Nowly.

Authorization failure or timeout

  1. Confirm that login and consent were completed in the system browser.
  2. Keep Nowly’s connection flow open until the browser says authorization is complete.
  3. Check system time, network access, proxy settings, and Google service availability.
  4. Return to Nowly and wait for the calendar list; reconnect if the problem continues.

When contacting support, include the Nowly version, Windows version, time of the issue, and an error description that contains no personal calendar data. Never send a password, OAuth credential, token, or complete log.

Disconnect an account

Find the connected account in calendar settings and choose Disconnect. See Data Deletion for details.
