# 专注计时简化与全球化设计

## 目标

简化专注计时模块的视觉与操作，并让该功能完整支持简体中文和英文。改动必须遵循根目录 `design.md`，不引入动效或新的视觉 Token。

## 范围

### 专注计时卡片

- 移除卡片内部的“专注计时”标题，但模块在添加模块列表和编辑布局工具栏中仍保留本地化名称，确保模块可识别。
- 保留卡片 Header 中的统计入口，但按钮仅显示统计图标；按钮必须具有随语言变化的可访问名称。
- 重置按钮仅显示图标，不显示“重置”等可见文字；按钮必须具有随语言变化的可访问名称。
- 完全移除全屏按钮和全屏专注功能。
- 卡片底部保留“近 7 天专注分钟数”摘要及其统计入口，但不再显示迷你折线图。
- 继续保留时长预设、自定义时长、开始、暂停、继续和重置能力。

### 壁纸模式

- 壁纸模式不可操作。专注计时卡片仅显示倒计时与提示文字。
- 隐藏统计入口、时长预设、自定义时长、开始、暂停、继续和重置等全部操作控件，也不提供全屏入口。
- 提示文字说明用户可以双击回到前台后操作专注计时。
- 双击行为沿用现有实现：在壁纸任意区域双击后切换回前台模式，不增加新的双击计时行为。

### 专注统计弹窗

- 保留近 7 天、近 30 天、近 12 个月周期选择。
- 保留总专注时长、完成次数、中断次数和完成率四项摘要。
- 移除折线图、图表空状态和折线图图例。无数据时仍可展示值为零的摘要。
- 保留统计加载失败后的错误提示和重试操作。

### 移除全屏功能

- 删除专注卡片的全屏入口。
- 停止渲染专注全屏覆盖层，并移除进入、退出全屏的前端 API 与自动进入全屏逻辑。
- 删除仅服务于专注全屏界面的组件、样式和测试。
- 不改变桌面窗口自身的前台/壁纸模式切换。

## 全球化

专注功能的以下内容全部通过现有 `src/i18n` 翻译机制提供简体中文和英文：

- 计时卡片中的状态提示、预设、自定义时长表单、校验错误和操作名称。
- 纯图标统计与重置按钮的可访问名称。
- 壁纸模式的双击提示。
- 统计弹窗标题、说明、周期、摘要、错误及重试文字。
- 专注完成的系统通知标题和正文。

计时数字和 `MM:SS` 格式不随语言变化。分钟、次数等单位使用自然的中英文表达。模块注册表已有的中英文名称和说明继续复用。

## 组件与数据流

- `App` 将当前窗口模式传给 `FocusTimerWidget`，由组件根据 `foreground` 或 `wallpaper` 渲染不同内容。
- 前台模式使用现有计时状态和命令；壁纸模式只读取剩余秒数与状态，不触发任何计时操作。
- `FocusTimerContext` 保留计时状态机、原生后台计时、会话持久化和统计加载；只移除全屏相关状态调用，并使用当前语言生成原生通知快照。
- `FocusStatisticsDialog` 继续读取同一统计资源，但仅渲染周期控件、摘要和错误状态。
- 不修改数据库结构、Rust 统计查询或已有专注记录。

## 错误处理与可访问性

- 自定义分钟数继续限制为 1–720 的正整数，并显示本地化错误。
- 统计加载失败时显示本地化 `role="alert"` 和重试按钮。
- 所有纯图标按钮必须有本地化 `aria-label`。
- 倒计时保留 `role="timer"`。
- 壁纸模式不渲染可聚焦的专注操作控件，避免呈现无法执行的交互。

## 测试

- 更新计时卡片测试，验证标题和折线图不存在、统计与重置按钮仅有图标、全屏按钮不存在。
- 增加英文模式测试，覆盖卡片状态、按钮可访问名称、自定义时长校验和统计弹窗。
- 验证壁纸模式只显示倒计时和双击提示，且没有专注操作按钮。
- 更新统计弹窗测试，验证摘要与周期切换保留、折线图与图例不存在。
- 更新 Context 测试，验证中英文系统通知内容。
- 删除全屏组件测试，并运行完整前端测试与构建。

## 非目标

- 不移除专注统计数据、会话记录或数据库表。
- 不改变专注时长计算、暂停/继续语义和会话保存规则。
- 不新增语言，不修改应用其他模块的全球化范围。
- 不改变现有壁纸双击返回前台的行为。
