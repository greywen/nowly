# Good 离线单日期选择器设计规格

日期：2026-07-29

## 1. 目标

在 `docs/prototypes/nowly-final-uiux.html` 中，将弹窗内的原生日期输入替换为参考 Good Date Range Picker 文档的离线单日期选择器，同时保持主界面日程月历不变。

参考页面：

`https://preview.keenthemes.com/html/good/docs/?page=forms/daterangepicker`

Good 文档通过 Date Range Picker 插件的 `singleDatePicker` 模式实现单日期选择。本原型不引入完整插件依赖，而是在单文件中复刻其结构、视觉和必要交互。

## 2. 应用范围

只应用于：

- 日程编辑弹窗中的“日期”。
- 任务编辑弹窗中的“截止日期”。

不应用于：

- 主界面月历。
- 开始时间与结束时间。
- 设置中的日期格式下拉框。

## 3. 输入控件

每个日期字段使用 Good Solid 输入外观：

```html
<div class="date-picker-field" data-date-picker data-value="2026-07-23">
  <button class="input date-picker-trigger" type="button" aria-haspopup="dialog" aria-expanded="false">
    <span data-date-value>2026 年 7 月 23 日</span>
    <svg class="icon" aria-hidden="true">...</svg>
  </button>
</div>
```

规则：

- 高度：`48px`。
- 背景：`#F8F6F2`，对应 Good `form-control-solid`。
- 边框：默认透明；打开或 focus-visible 时使用主色焦点状态。
- 圆角：`15.2px`。
- 左右内边距：`16px`。
- 文字：`16px / 400 / 1.5`，颜色 `#716D66`。
- 日历图标：`18px`，颜色 `#8E887A`。
- 整个控件可点击，不使用浏览器原生 `type="date"` 面板。
- 控件保留可访问名称“日期”或“截止日期”。

## 4. 共享日期面板

两个输入控件共用一个日期选择面板实例。面板在当前触发控件附近显示，并限制在弹窗可视范围内。

面板结构：

```text
Date Picker Popup
├─ Header
│  ├─ 上一个月
│  ├─ 2026 年 7 月
│  └─ 下一个月
├─ Weekdays（周一至周日）
├─ 6×7 日期网格
└─ Footer
   ├─ 清除
   └─ 今天
```

面板规则：

- 宽度：`320px`。
- 白色背景：`#FFFFFF`。
- 边框：无；通过 Dropdown 阴影建立层级。
- 圆角：`15.2px`。
- 阴影：`0 0 50px 0 rgba(82, 63, 105, 0.15)`。
- 内边距：顶部与日期区 `16px`。
- z-index 高于弹窗 Body 内容，低于弹窗关闭控制层级没有额外要求。
- 不使用背景模糊。

## 5. 日期网格样式

### 5.1 Header

- 月份标题：`15.2px / 600`，颜色 `#403D38`。
- 上下月按钮：`35×35px`，圆角 `15.2px`，中性背景。
- Hover：背景 `#F8F6F2`、图标 `#4FC9DA`。

### 5.2 星期标题

- 七列，从星期一开始。
- 字号：`13.6px / 500`。
- 颜色：`#968E7E`。
- 每格高度：`32px`。

### 5.3 日期按钮

- 使用 6×7 共 42 个日期按钮，保证每月布局稳定。
- 每格最小尺寸：`36×36px`。
- 字号：`13.6px / 500`。
- 默认文字：`#716D66`。
- 圆角：`15.2px`，匹配 Good 定制后的日期单元格。
- Hover：背景 `#F8F6F2`，文字 `#4FC9DA`。
- 非当前月：背景透明，文字 `#968E7E`。
- 已选中：背景 `#4FC9DA`，文字 `#FFFFFF`。
- 今天但未选中：背景 `#F6F1E9`，文字 `#716D66`。
- 今天且已选中：选中样式优先，仍使用主色背景与白字。
- 不增加缩放、位移或颜色过渡。

### 5.4 Footer

- 顶边界：`1px solid #F6F1E9`。
- 内边距：`12px 16px`。
- “清除”：次级文本按钮。
- “今天”：主色浅背景按钮或主按钮小尺寸样式。
- 两个操作均即时生效。

## 6. 日期状态与格式

- 内部日期值使用 ISO 格式 `YYYY-MM-DD`。
- 显示格式使用 `YYYY 年 M 月 D 日`。
- 初始日程日期：`2026-07-23`。
- 初始任务截止日期：`2026-07-23`。
- 点击日期后更新当前字段的 ISO 值和显示文字，并关闭面板。
- “今天”使用原型固定演示日期 `2026-07-23`，避免系统日期造成演示内容不稳定。
- “清除”将当前字段值置为空，显示 `选择日期`，然后关闭面板。
- 月份切换只改变面板显示月份，不提前修改字段值。

## 7. 交互

- 点击日期触发控件打开面板。
- 同一时间只能打开一个日期面板。
- 再次点击当前触发控件关闭面板。
- 点击另一个日期字段时，面板切换到该字段的值与位置。
- 点击面板外部关闭。
- `Esc` 关闭并将焦点返回触发控件。
- 选择日期后关闭并将焦点返回触发控件。
- 关闭父级业务弹窗时必须同时关闭日期面板。
- 日期面板状态不写入 localStorage。

## 8. 键盘与无障碍

- 触发控件使用原生 `<button>`，提供 `aria-haspopup="dialog"` 和 `aria-expanded`。
- 日期面板使用 `role="dialog"`，并通过标题关联当前月份。
- 日期网格使用 `role="grid"`。
- 星期标题使用 `role="columnheader"`。
- 日期按钮使用 `role="gridcell"` 或位于具有该角色的容器内，并提供完整中文日期 `aria-label`。
- 已选日期提供 `aria-selected="true"`。
- 今天提供 `aria-current="date"`。
- 打开后焦点进入已选日期；没有值时进入固定今天；若均不在当前显示月，则进入当月 1 日。
- 左右方向键移动一天。
- 上下方向键移动七天。
- PageUp/PageDown 切换前后一个月。
- Enter/Space 选择当前日期。
- Tab 可访问上月、下月、日期网格、“清除”和“今天”。

## 9. 动效限制

- 面板显示、关闭和月份切换即时完成。
- 不引入 Date Range Picker 插件原有 transition。
- 不使用淡入、缩放、位移或平滑滚动。
- 继续执行全局无动效规则。

## 10. 离线与依赖

- 不引入 jQuery。
- 不引入 Moment.js。
- 不引入 Date Range Picker 完整 JS/CSS Bundle。
- 不加载 CDN 或网络字体。
- 使用原生 `Date` 和少量 Vanilla JavaScript 生成 42 个日期单元格。
- `file://` 直接打开时必须完整可用。

## 11. 设计规范更新

在根目录 `design.md` 增加“日期选择器”组件规范，包括：

- Good Solid 日期触发控件。
- 320px 白色日期面板。
- Dropdown 阴影与 15.2px 圆角。
- 日期各状态颜色。
- 键盘与 ARIA 规则。
- 无网络、无动效要求。

## 12. Checkbox 对比度并行修复

完成此前已确认但尚未实施的单一修复：

- 未选中 Good Solid Checkbox/Radio 背景从 `#F6F1E9` 改为 `#DAD3C3`。
- 保持无边框。
- 选中背景仍为 `#4FC9DA`。
- `design.md` 和 Playwright 计算样式测试同步更新。

该修复与日期选择器无逻辑依赖，但在同一轮交付中完成，避免工作区保留失败测试。

## 13. 验收标准

1. 主界面月历结构与事件展示不变。
2. 原型中不再存在 `input[type="date"]`。
3. 日程日期和任务截止日期显示 Good Solid 触发控件。
4. 两个字段共用一个日期选择面板。
5. 面板为 320px 白底、15.2px 圆角、Good Dropdown 阴影。
6. 日期面板显示 42 个日期按钮和周一至周日表头。
7. 已选日期、今天、非当前月和 hover 状态符合本规格。
8. 选择、清除、今天、月份切换均可用。
9. 点击外部和 Esc 可关闭，焦点正确归还。
10. 日期面板关闭父级弹窗时不会残留。
11. 日期触发控件和网格具备规定 ARIA 属性。
12. 键盘方向键、PageUp/PageDown、Enter/Space 可操作。
13. 页面继续无动画、无网络依赖。
14. 1366×768 到任意更大视口无页面级溢出。
15. 未选中 Checkbox/Radio 计算背景为 `#DAD3C3`。
16. 现有五类弹窗、任务完成、设置和月份标题测试继续通过。
