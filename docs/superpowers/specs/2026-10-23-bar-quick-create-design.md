# Nowly Bar 快速创建设计规格

日期：2026-10-23
状态：用户已确认设计，已实现于 `feature/bar-quick-create`。视觉规范以根目录 `design.md` §8.3、§10.11.1、§12.3、§14.1 为准。

## 目标与范围

不打开主窗口，直接新建日程、四象限任务和便签：

- 入口一：Nowly Bar Logo 功能菜单中的「快速创建」磁贴。
- 入口二：可选的全局快捷键，默认不设置。
- 同时把功能菜单重排为「快速创建」「截图」两组。

不包含：编辑或删除已有记录、看板视图新建、AI 助手入口恢复（继续隐藏）。

## 功能菜单

- 尺寸 `432 × 288px` 与头部不变。正文两组，组顺序固定：快速创建在上，截图在下。
- 快速创建组：日程、四象限任务、便签三枚等宽磁贴并排。首行左侧图标、右侧快捷键；名称在图标下方。快捷键只在设置后显示；已设置但注册失败时显示「快捷键不可用」。
- 截图组：截图、截图历史两项并排，沿用列表项样式，名称在上、快捷键在下。
- 名称、快捷键、提示文字最多两行，超出以省略号结尾，完整文字保留在可访问名称中。
- 组内全部隐藏时隐藏组标题；全部隐藏时显示现有设置引导空态。
- 方向键按视觉顺序线性移动（RTL 左右互换），`Home` / `End` 跳到首末项。Bar 家族不绘制焦点环（`design.md` §8.3）。
- 点击磁贴：先收起菜单，再打开快速创建窗口。

## 快速创建窗口

- 独立原生窗口 `quick-create`：首次使用时创建，关闭后隐藏复用。透明、无标题栏与系统边框、无系统阴影、置顶、不进任务栏、不可调整尺寸。
- 复用应用内 `EventModal`、`UnifiedTaskDialog`、`NoteModal`，不做精简版。任务按四象限视图新建：默认「重要且紧急」与默认泳道。
- 几何：
  - 宽度：日程 `720`、任务 `680`、便签 `760`（逻辑像素）。
  - 位置：Bar 折叠态正下方 `8px`；Bar 隐藏时按其应在位置计算。水平中心对齐 Bar，左右距工作区至少 `8px`，不足时收窄。
  - 高度：跟随弹框内容，最高到工作区底边留 `16px`（不低于 `240px`），超出时只有 Body 滚动。
- 弹框铺满窗口，无遮罩，`--shadow-none`，保留默认边框与圆角。出现、切换、关闭均即时完成。
- 焦点：窗口出现即获得焦点，落在第一个输入。
- 关闭：
  - 保存成功即关闭，并通知主窗口静默刷新；保存失败保持打开并显示错误。
  - 取消、关闭键、`Esc`、`Alt+F4` 走现有关闭流程，有改动时先确认放弃。
  - 点击窗口外部或切换应用不关闭。
- 再次触发：同一类型聚焦已开窗口并保留草稿；不同类型在草稿未改动时直接切换，有改动先确认放弃，取消则保留原草稿。
- 截图：截图期间隐藏窗口，结束后恢复且不抢焦点；截图进行中忽略打开请求。

## 设置

- 通知 → Nowly Bar → 功能菜单：按两组列出，组内显示/隐藏与上移/下移，组顺序固定。新项默认显示，旧数据升级时追加三个创建项，组内默认顺序为日程、任务、便签。
- 快捷键页新增「快速创建」分区：新建日程、新建四象限任务、新建便签三个录制框。
  - 默认为空，显示「未设置」，带清除按钮。
  - 五个全局快捷键互不重复，前端与 Rust 都校验。
  - 空槽不注册，注册失败只影响对应项。

## 架构

- Rust 入口 `quick_create::open(app, kind)`，Bar 菜单命令和全局快捷键共用：
  1. 截图中直接忽略。
  2. 收起 Bar 菜单。
  3. 读取 Bar 锚点。
  4. 确保窗口存在，生成新请求。
  5. 向窗口发送 `quick-create-open`。
- 命令（均为 async，校验调用窗口）：
  - `open_quick_create(kind)`：`main`、`quick-panel-handle` 可调用。
  - `get_quick_create_request()`、`quick_create_layout(requestId, kind, height)`、`close_quick_create(requestId)`：仅 `quick-create` 窗口。
- 首次 `quick_create_layout` 定位、显示并聚焦窗口，之后只调整高度；过期请求 id 被忽略。
- 原生 `CloseRequested`（如 `Alt+F4`）被拦截，改发 `quick-create-close-requested`，由前端按草稿状态决定是否确认。
- 快捷键注册表由 2 槽泛化为 5 槽：截图、截图历史必填，三个创建槽可空。
- 前端 `QuickCreateApp`：
  - 先监听、再拉取当前请求。
  - 用弹框的 `onDirtyChange` 判断草稿状态。
  - 测量弹框高度上报布局；同一请求、类型、高度不重复上报。
- 保存后发 `nowly-records-changed {kind: event | task | note | category}`。主窗口按类型静默刷新：
  - 日程：事件列表。
  - 分类：分类与事件。
  - 任务：任务工作区。
  - 便签：便签列表。
  - 刷新时不进入读取中状态。

## 测试

- Rust：几何计算、请求生命周期、快捷键 5 槽校验与注册、窗口事件分支。
- Vitest：菜单模型与分组面板、设置界面、`QuickCreateApp`（StrictMode）、弹框 `onDirtyChange`、主窗口静默刷新、浏览器 shim 命令。
- Playwright：`tests/nowly-bar-menu.spec.ts` 覆盖分组、磁贴、方向键、两行省略、打开快速创建与收起菜单。
