# 月视图日程纵向对齐设计

## 背景

月视图中，跨日日程条的顶部位置为 `30px`，单日日程列表的顶部位置为 `36px`。因此跨日日程比单日日程高 6px，更靠近日期文字，造成同类内容在日期格中的视觉位置不一致。

## 目标

- 跨日日程与单日日程使用一致的日期下方起始位置。
- 保持跨日日程跨列连接、分 lane 堆叠、拖动和缩放行为不变。
- 保持同一日期格中的单日日程位于跨日日程之后，避免重叠。
- 不改变周、日和列表视图。

## 方案

采用最小范围样式修复：

1. 将月视图跨日日程容器 `.calendar-week-row__bars` 的顶部位置从 `30px` 调整为 `36px`，与 `.day-singles` 一致。
2. 同步调整 `CalendarWidget` 中存在跨日 lane 时的单日日程顶部补偿量，使单日日程仍从跨日日程区域之后开始。
3. 保留现有日程条高度 `20px`、间隔 `4px` 和 lane 步长 `24px`。

## 交互与数据

本次仅调整月视图布局，不改变组件接口、事件数据、排序、溢出、拖动或缩放的数据流。无新增错误状态。

## 验证

- 增加或更新浏览器布局回归测试，比较同一周中首条跨日日程和无跨日覆盖日期内首条单日日程的顶部坐标，预期一致。
- 验证同一日期内同时存在跨日与单日日程时，两者不重叠，间距保持 4px。
- 运行相关组件测试和 Playwright 布局测试。

## 范围外

- 不重构月视图日程布局架构。
- 不修改日程条颜色、字号、圆角或高度。
- 不调整周视图、日视图或列表视图。
