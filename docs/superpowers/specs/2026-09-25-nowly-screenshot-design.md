# Nowly 桌面截图：完整交互规格

日期：2026-09-25

状态：功能范围、详细交互、D02 与容量边界已由用户确认；进入实施阶段。

性质：设计文档，不代表功能已实现或技术验证已通过。

配套文档：[技术验证清单](2026-09-25-nowly-screenshot-validation.md)。

## 1. 范围与决策

### 1.1 已确认的最终功能

- 从 Nowly Bar 的独立截图按钮启动，截取 Windows 桌面，而非仅截取 Nowly 页面。
- 框选前显示像素放大镜、物理像素坐标、HEX 色值；Ctrl+C 复制色值后仍可继续截图。
- 矩形框选、选区移动、八向尺寸调整、尺寸提示。
- 矩形、椭圆、箭头、画笔、文字、马赛克；对象选择、修改、删除、撤销与重做。
- 垂直滚动长截图：手动滚动为默认；自动滚动为显式可选方式。
- 复制最终图片、另存为 PNG、取消并恢复 Bar。
- 本地处理，不增加服务器或上传流程。

不包含 OCR、翻译、贴图、分享、云同步、截图历史、录屏、定时截图、网页 DOM 整页导出及新的全局启动快捷键。不因参考图出现这些图标而加入范围，也不保留不可用占位入口。2026-09-30 已确认加入悬停识别窗口和单击选窗，普通截图交互以 `2026-09-30-screenshot-interaction-amendment.md` 的修订为准。

### 1.2 本次详细规格提案

| 决策 | 明确行为 |
|---|---|
| 系统范围 | Windows 桌面；不在此次增加 macOS/Linux 实现 |
| 普通截图 | 支持单屏和跨显示器矩形选区；使用统一虚拟桌面物理像素坐标 |
| 滚动截图 | 单显示器内的一个垂直滚动内容区域；不拼接跨屏、横向或双向滚动 |
| 取色来源 | 本次冻结底图的 sRGB 像素；不是实时桌面、显示器物理色度或网页源代码颜色 |
| 默认输出 | 复制扁平化后的图片；保存为原始像素尺寸 PNG，不默认缩放 |
| 长图顺序 | 先采集、拼接、确认结果，再进行标注 |
| 部分结果 | 匹配不确定时暂停；只有用户明确选择“使用已截部分”后才能作为结果导出 |
| 权限 | 不自动提权；不绕过系统安全桌面、应用捕获保护或 DRM |
| 并发 | 同一进程最多一个截图会话；重复点击不创建第二套覆盖层 |

### 1.3 已选择的技术路线

采用“Nowly 自有界面 + 可替换的原生抓屏适配器 + 独立编辑/拼接模块”。整套自研的基础工作更多；直接启动外部工具无法由 Nowly 统一控制本次会话。已经讨论过的路线不在本轮重新开放选择。

`xcap`、`react-screenshots`、Tauri Clipboard 及 `snow-stitch-images` 均为技术验证候选，不是已经确定接入的依赖。候选不通过验证时可替换实现，不擅自删除已确认功能。依赖选择由验证清单 V00 决定。

## 2. 设计依据与 design.md 的待确认修订

根目录 [design.md](../../../design.md) 始终是唯一视觉权威。D01 已确认、已实现并已同步到 `design.md`；D02 已确认并同步到 `design.md` §14。

### 2.1 D01：截图入口改为 Bar 应用按钮位（已实现）

本条已由「Nowly Bar 应用按钮」一轮实现，并同步进 `design.md` §8.3 / §12.3，几何以 `design.md` 为准。原提案「408 宿主内 336 折叠外壳、截图区固定在 x=276」的写法已作废。

实际形态：折叠外壳宽 `288 + 48 × 应用按钮数`，高 40；左 240 状态操作，其右 48 为 Nowly Logo，Logo 之后依次排列 0 至 3 个 48px 应用按钮位。截图是应用按钮目录中的一项，由用户在「设置 → Nowly Bar → 应用按钮」中加入或移除，不是写死的入口。

对本文其余部分仍然成立的约束：

- 应用按钮位内是 §10.1 紧凑档图标按钮：`28 × 28`、圆角 `7.6px`、图标 `16px`，在 `48 × 40` 的位内居中。顶部轨道禁止 `40 × 40` 图标按钮。
- 每个应用按钮位左边缘复用 Logo 区的 1px、22px 高、上下 9px 分隔线规则。
- 截图入口只在折叠且无形变过程时可交互；状态/AI 面板展开时应用按钮随 Logo 一同淡出并退出 Tab 序列，不额外复制截图按钮。
- 截图按钮不触发状态详情、不确认提醒、不调用 `toggle_nowly_panel`，也不参与 Bar 拖动。
- 真实 Bar 只渲染已配置的按钮，不渲染空位占位符；加号只存在于设置内的 Bar 预览中。
- 原生命中区域按每种真实可见形态计算，留白随按钮数变化（见 `design.md` §8.3 的左边缘表），不写死「两侧各 60」。
- 三种形态都维持逻辑坐标，不改变保存的 Bar 横向偏移；屏幕边界钳制按可见区域计算。
- 现有 Fluid Morph 时长、允许属性和 reduced-motion 规则保持。新增截图覆盖层没有展开/收起补间动画。
- 截图入口的 hover、active、focus-visible、disabled 使用紧凑图标按钮规范，提供「截屏」的可访问名称与 Tooltip。

实现接缝：截图按钮调用 `start_screen_capture`（`src-tauri/src/screen_capture.rs`）。该命令目前返回「截图功能尚未可用。」，按钮在原地以静态文案报告该结果。本文实现时替换该命令的函数体，Bar、设置界面与前端目录都不需要改动。

### 2.2 D02：区分截图内容与应用控件（已确认并同步）

`design.md` §14 已增加截图专节，明确以下是数据呈现或几何编辑，不是新的应用视觉体系：

- 截图原始像素、矩形裁切边界不应用 15.2px 圆角，PNG 不裁掉四角。
- 绘制内容的笔宽、字号、马赛克块尺寸以输出物理像素计，不受应用 UI 的装饰边框宽度/字号限制。
- 选区控制点为 8×8 的实心方形几何标记，24×24 的透明命中区域；不套用普通按钮圆角。
- 放大镜像素网格采用最近邻显示，不做玻璃模糊或装饰动效。
- 本次标注色板只使用既有主色、功能色、`--text-primary`、`--text-inverse` 八色，不增加一套主题色。
- 工具栏、弹层、表单、按钮、提示文案仍严格遵守现有 Token、Solar 图标、手写语义化 CSS 和无补间规则。

本文中的专用尺寸是待纳入截图专节的几何常量，不可借此为其他组件添加例外。

### 2.3 截图界面固定规格

| 元素 | 规格 |
|---|---|
| 非选区遮罩 | `--bg-overlay`；仅用于冻结截图的交互层，不写入输出 |
| 选区边框 | 1px `--color-primary`；八个控制点同色；不写入输出 |
| 尺寸标签 | `宽 × 高 px`；0.95rem；`--bg-surface` 底、`--text-strong` 字；距边界 8px |
| 放大镜卡片 | 宽 192px，内边距 12px，圆角 `--radius-default`，默认边框，`--shadow-sm` |
| 放大网格 | 21×21 个来源像素，8 倍显示为 168×168；中间一格为目标像素；1px 主色十字线 |
| 放大镜信息 | 坐标、色值两行与常驻快捷键说明；0.95rem；仅 HEX 使用 `--font-mono` |
| 编辑工具栏 | 内边距 8px、按钮间距 8px、组间分隔 1px；白色表面、默认边框、默认圆角、`--shadow-sm` |
| 编辑工具按钮 | 独立截图界面的标准档：40×40、18px Solar 图标，不沿用 Bar 的紧凑档 |
| 工具属性弹层 | 使用 §10.5/§10.6 的控件及状态，距所属工具栏 8px，不使用胶囊 Tab |
| 状态/错误反馈 | 来源控件或相关内容旁的静态文案；不使用 Toast、全局 Banner、spinner |

放大镜与指针保持 16px，优先右下；不够放时翻到另一侧，距显示器可见边界至少 8px。靠边时不遮住目标像素；取不到的网格格子显示中性底，不把填充色当作可复制像素。

若显示器当前可用空间不足以容纳标准卡片，网格降为 11×11 来源像素、仍为 8 倍显示；再放不下时隐藏网格，只保留坐标、HEX 和快捷键三行。该退让只作用于放大预览，不缩小字号或按钮，也不是新增全局媒体断点。

工具栏优先在选区下方 8px，右端与选区右端对齐；放不下则翻到上方，再钳制到当前显示器内 8px。仍无法放在选区外时可放在选区内，但必须不遮住正在操作的控制点，并可通过顶部拖动区域临时移位；它始终不进入输出像素。

工具栏使用固定工具分组换行适配可用宽度，不缩小按钮、不隐藏完成/取消，不横跨显示器边界。不得另设与 `design.md` 冲突的视口断点。属性弹层靠屏幕边缘时翻转并保持完整可达。

## 3. 会话生命周期

### 3.1 状态与主要转移

| 状态 | 可执行动作 | 结束/异常行为 |
|---|---|---|
| IDLE | 点击 Bar 截图 | 创建唯一会话，进入 STARTING |
| STARTING | 取消启动 | 保存 Bar 状态并取得临时抑制权；隐藏 Bar，抓取底图；失败清理后恢复 |
| AIMING | 移动取色、复制色值、开始框选 | Esc 取消整个会话 |
| SELECTING | 指针拖动、调整框选终点 | 松开后进入 EDITING；Esc 只撤销本次拖选 |
| EDITING | 调整无标注选区、绘图、修改对象、复制、保存、进入滚动准备 | 按键按 §7 分派；失败留在此状态 |
| SCROLL_PREPARE | 选择手动/自动、确认内容区域和目标、开始或返回 | 返回/Esc 进入原普通截图 EDITING |
| SCROLLING | 手动滚动或自动滚动；暂停、停止、取消长截图 | Esc 停止采集并进入 SCROLL_REVIEW，不销毁已截内容 |
| SCROLL_PAUSED | 查看暂停原因、继续、查看已截部分、取消长截图 | Esc/查看已截部分进入 SCROLL_REVIEW；只有明确继续才重新采集 |
| SCROLL_REVIEW | 查看拼接结果，确认使用或取消长截图 | 确认后进入长图 EDITING；取消/Esc 丢弃长图并回到原普通截图 EDITING |
| EXPORTING | 系统保存对话框可取消；编码阶段可取消导出；提交阶段等待真实结果 | 成功进入 CLOSING；失败/对话框取消/编码取消回到 EDITING，见 §8.1 |
| CLOSING | 不再接受新操作 | 停止采集/输入，销毁覆盖层，释放数据，解除 Bar 抑制权，回到 IDLE |

“编辑文字、拖动对象、正在绘制、属性弹层打开”是 EDITING 内的互斥局部状态，不创建新的原生截图会话。状态转移带会话 ID 与递增版本，旧异步结果不能复活已经结束的截图。

### 3.2 启动与冻结画面

1. 截图只由用户明确点击启动；启动前不后台采屏。
2. 记录 Bar 所在显示器、逻辑横向位置、可见性、折叠状态及焦点信息。“原前台目标”必须在 Bar 获得激活前保存，或读取最后一个非 Bar/截图辅助窗的有效前台身份，不能在按钮点击后把 Bar 自己记录成原目标；该目标可以是用户本来就在操作的 Nowly 主窗口。只保留本次所需身份，不建立窗口活动历史。
3. 取得截图专用临时抑制权，阻止提醒展示、Bar 自动重定位、失焦收起逻辑争抢窗口；提醒数据、计时、AI 请求继续按原业务运行。
4. 隐藏 Bar 与所有自有截图辅助窗口，等待合成状态更新后抓取各显示器的不可变底图；不是先显示遮罩再截图，也不能只靠固定 sleep 猜测已隐藏。每屏必须属于本次 hide-generation 之后的新帧，不能把上次缓存帧拼入本次；任何一屏失败都放弃整次启动。
5. 准备好底图后才显示覆盖层。默认不包含鼠标光标。Nowly 主窗口不隐藏，可以被正常截图。
6. 每屏一个覆盖窗口，由同一 Rust 会话统一维护物理坐标与选区。跨屏抓图不承诺运动内容同一时刻的硬件级同步。
7. 进入 AIMING。STARTING 从启动请求起最多 5 秒，超时走失败恢复，而非展示部分屏幕的假成功结果；该超时是故障上限，不是正常性能目标。只要未选择滚动模式，底图不随应用变化重新捕获。

### 3.3 恢复与故障

- 恢复使用“解除临时抑制，再按当前业务状态协调”的方式，不把旧的提醒/AI 数据快照覆盖回去。
- 普通成功/取消恢复原显示器和横向位置；原显示器已经断开时使用现有主屏降级策略，不篡改已保存的用户显示器偏好。
- 截图过程中新增提醒可以排队，结束后按现有提醒规则显示；不得被标记为已读，也不在截图中临时弹出 Bar。
- 不关闭 AI 会话、不清空输入、不取消后台请求。截图入口只在折叠态可用，因此常规恢复目标仍是折叠态。
- 保存系统对话框的焦点切换不视为目标应用切换；对话框以截图编辑器为 owner，关闭后焦点回到原工具。
- 普通截图 Alt+Tab 时不持续抢焦点或主动退出；隐藏辅助覆盖层，保留唯一一个可由 Alt+Tab/任务栏返回的“Nowly 截图”会话入口。每屏辅助窗口不能各自形成任务切换项。用户返回时恢复原底图，不重新抓屏；切到自己的保存对话框不触发这套挂起逻辑。
- 该任务切换入口的 Alt+Tab、任务栏悬停缩略图和 Peek 使用静态 Nowly 截图占位，不展示冻结桌面或未打码内容；挂起时也不得留下上一帧的敏感缩略图。
- 最终退出仅在原前台窗口仍有效、属于原桌面且用户未主动切到其他应用时尝试一次恢复其焦点；恢复属于尽力而为，不循环抢焦点，也不打开无关的 Nowly 主窗口。Bar 本身的可见区域/状态恢复仍必须确定完成。
- 滚动模式下切换到无关应用必须暂停采集和自动输入；不得继续向新前台应用发送滚轮。
- 取消、捕获失败、覆盖层创建失败、锁屏、桌面会话切换、显示器配置变化、退出应用都停止捕获/输入并清理失效辅助窗口；是否保留结果按下一条决定。只有整个会话结束才释放仍可供用户确认的底图。
- 普通截图遇到显示器拓扑/DPI 变化时停止使用旧坐标并安全取消；滚动截图停止采集并保留可用的已截部分供确认。锁屏/安全桌面切换则结束整个截图，不自动恢复采集。
- 前端窗口失联由 Rust 兜底关闭覆盖层、停止任务并恢复 Bar。整个进程被终止时，窗口随进程销毁；下次启动按正常设置重建，不承诺崩溃后保留截图。

## 4. 放大镜、坐标与选区

### 4.1 坐标和色值

- `X, Y` 是 Windows 虚拟桌面的有符号物理像素坐标；主屏左上角为 (0, 0)，左侧/上方副屏允许负数。
- 显示器逻辑坐标、WebView CSS 坐标与截图像素必须显式换算，不全局乘同一个缩放系数。
- HEX 固定为大写六位 `#RRGGBB`，Ctrl+C 只写入这 7 个字符，无坐标、换行或其他格式。
- 采样在该显示器的冻结底图原始像素上执行，不采样缩放后的 Canvas、遮罩或十字准星。
- sRGB 化后的底图用于取色、预览和导出三条路径，不能分别转换产生不一致；HDR 不宣称可与原始 HDR 数值逐字节相同。
- 桌面空隙/失效帧显示“无有效像素”，Ctrl+C 不改剪贴板，不能沿用上一次色值。
- 复制成功仅把放大镜提示替换为“色值已复制”，下一次移动恢复“按 Ctrl+C 复制色值”；失败在同一位置显示“复制失败，请重试”，会话保持。

### 4.2 框选

- 左键拖动产生矩形，支持任意方向；选区以整数物理像素半开区间保存，宽高取实际输出像素数。
- 悬停高亮冻结底图中的最上层有效窗口；无拖动的单击选中该窗口，没有候选窗口时保持 AIMING，不产生空图片。拖动始终优先形成自定义选区。最小有效选区为 1×1，可用键盘精确调整。
- 拖选时显示尺寸与放大镜；完成框选后隐藏放大镜并显示工具栏。
- 选区覆盖多个显示器时按统一物理坐标拼成一张图片，不对副屏进行统一 DPI 重采样。虚拟桌面无显示器的空隙在输出中填白，不提供可取色像素。
- 跨屏拖动由原生会话/指针捕获协调，不依赖某个 WebView 永远能收到相邻显示器的 pointermove。
- 无标注时，可拖动选区内部移动截取范围，拖动八个控制点改变范围；边界不能越出本次捕获的虚拟桌面包围矩形。
- 首个标注提交后锁定截取范围；提示“已开始标注，撤销全部标注后可调整选区”。对象仍可编辑，不把“移动选区”误解释为“移动标注”。
- 未发生标注的选区按右键回到 AIMING；有标注时右键只取消当前工具/对象选择，不清空内容。取消整次截图使用明确的取消按钮或无局部上下文的 Esc。
- 指针捕获丢失、`pointercancel` 或拖动期间 Alt+Tab 只撤销当前未提交的选区/笔画/对象变换，回到动作前状态；不得把最后一个已知位置自动当作成功提交。已经提交的标注不受影响。

## 5. 标注编辑

### 5.1 工具栏顺序与默认状态

固定分组：

1. 选择、矩形、椭圆、箭头、画笔、文字、马赛克。
2. 撤销、重做、滚动截图。
3. 保存、取消、完成。

初次框选默认“选择”。图标必须有 Tooltip/可访问名称，状态通过 `aria-pressed` 与视觉反馈共同表达。完成的 Tooltip 明确写“复制图片并完成”，保存写“另存为 PNG”；不增加语义重复的独立复制按钮。

### 5.2 工具行为

| 工具 | 创建 | 提交后的编辑 |
|---|---|---|
| 矩形 | 拖动创建描边矩形；Shift 约束正方形 | 选择、移动、八向缩放、改颜色/线宽、删除 |
| 椭圆 | 拖动创建描边椭圆；Shift 约束正圆 | 同矩形 |
| 箭头 | 按住起点拖到终点；Shift 约束 45° 倍数方向 | 拖动端点、整体移动、改颜色/线宽、删除 |
| 画笔 | 按住绘制一条连续笔画，松开提交一次 | 整笔选择/移动、改颜色/线宽、删除；不拆成每个采样点撤销 |
| 文字 | 点击位置进入多行输入；中文 IME 正常使用 | 双击重新编辑；可移动、改颜色/字号、删除 |
| 马赛克 | 在选区内拖出矩形马赛克区域 | 选择、移动、缩放、调整块大小、删除 |

固定输出参数：

- 颜色：既有八色；默认 `--color-danger` 对应的颜色值。
- 图形/画笔线宽：2、4、8 个输出物理像素，默认 4。
- 文字：18、24、32 个输出物理像素，默认 24；使用 Nowly 正文字体，字重 500。以上是图像内容参数，不是 UI CSS 字号。
- 马赛克：8、16、24 个输出物理像素的块尺寸，默认 16；规则取样网格锚定图像原点，不随预览缩放改变。
- 新工具沿用本会话上次使用的同类属性，不跨会话持久化，不增加设置页面。
- 图形和鼠标落点均裁切到输出范围内；选区外的指针轨迹不能读入未授权范围之外的新桌面帧。
- 同时只能选择一个标注；不加入多选、编组、图层面板、图形旋转、任意自由变换。

### 5.3 文本、顺序与撤销

- 文字支持换行、选中、复制、粘贴、退格与中文候选输入；空文本不生成对象。
- 文本编辑时 Enter 换行，Ctrl+Enter 提交；点击非文本区域提交当前非空内容。Esc 撤销本轮文本编辑，已有对象恢复编辑前内容。
- 普通标注按创建顺序叠加；选择旧对象不自动改变其层级。
- 马赛克合成作为最终遮挡处理，作用于该区域已合成的底图和普通标注，避免先打码后加文字时意外把内容盖到马赛克上。它不是具有密码学保证的隐私消除工具。
- 马赛克块算法固定为：底图和普通标注先合成不透明的 8-bit sRGB 图；网格从图像 (0,0) 起按所选块大小划分；对“网格单元 ∩ 马赛克矩形 ∩ 图像”的有效像素逐通道取算术平均、四舍五入为整数，用该值填满这一交集。边缘不足整块时只统计实际像素，不补零。多个马赛克对象各自从同一份预马赛克合成图取样，按创建顺序覆盖交叠部分，保证可独立复算。
- 所有已提交的创建、修改、移动、缩放、删除都是一个撤销事务；拖动过程不逐帧入栈。
- Esc 中止的笔画/拖动/文本草稿不入撤销栈。新提交清空 redo 分支。
- 选区调整、取色复制和滚动采集不进入标注撤销栈；长图确认后是新的底图，空的标注历史。
- 撤销到无标注时，普通截图恢复选区调整与滚动入口；长图始终保持输出宽高，不回溯为普通截图。
- 撤销到零标注后，任何已完成且实际改变几何的选区调整都会清空标注 redo，防止旧对象在新裁切坐标上复活；中止调整并恢复原几何不会清空 redo。返回 AIMING 后重新框选也清空旧 redo。
- 导出必须使用同一图像/标注模型生成真实像素；不能通过“截取编辑界面 DOM”输出，不能残留可关闭的马赛克层或附带原始未打码图。

## 6. 滚动截图

### 6.1 启动条件和准备

滚动按钮在以下情况下禁用，并在按钮旁/Tooltip 提供具体原因：

- 选区跨显示器：“滚动截图需在同一屏幕内框选。”
- 已存在标注：“长截图需在标注前开始，可先撤销标注。”
- 当前底图已为长图：“当前已是长截图。”
- 捕获目标不可用或辅助窗口无法从采集结果中可靠排除：“当前环境无法安全开始滚动截图。”

准备面板使用原生 Radio 选择“手动滚动 / 自动滚动”，默认手动。显示内容范围、目标应用的本地可读名称及“只框选需要滚动的内容，避开固定侧栏和视频区域”的提示；该名称不进入文件或日志。

通过所选内容区域内的目标点确定原生窗口和滚动位置，默认选区中心；可在选区内重新点选目标点。该点击由截图层消费，只记录位置，不能穿透执行原应用按钮或链接。开始时使用非内容点击的方式尝试激活目标；无法可靠激活则提示用户激活后重试，不盲目注入滚轮。

保存普通截图底图、选区和标注历史状态，之后取消长截图可原样返回，包括撤销到零后保留的 redo。正式采集前撤下冻结底图与遮罩，让真实应用可交互；抓取新的第一帧作为拼接起点，不拿过时的普通截图强行拼接。只有确认采用长图时才丢弃普通截图历史。

### 6.2 采集中的界面

- 仅保留不遮挡操作的原生控制条和长图缩略预览，不保留盖住桌面的冻结全屏图片。
- 控制条显示：方式、已截高度、状态、暂停/继续、停止、取消长截图。
- 控制条与预览优先放在选区外；必须位于选区内时，只有窗口排除能力通过验证才能使用。
- 鼠标穿透、无激活窗口、窗口捕获排除是三个独立职责，分别验证。
- 预览只包含已确认拼接的像素前缀，随接受的新帧离散更新；待定/拒绝帧不能混在预览里冒充结果。无补间、无自动平滑滚动、无 spinner；不显示虚假的完成百分比。
- 停止原因、拒绝帧计数和已确认末端位置显示在预览旁。结果确认时在预览旁的标尺标记已接受接缝，支持聚焦并朗读编号/纵坐标、定位查看；这些标记不覆盖原图像素、不进入导出。
- 普通 Ctrl+C/Ctrl+S/Enter 不在全局截获，仍属于当前有焦点的应用。SCROLLING/SCROLL_PAUSED 仅为 Esc 设置临时、会话限定的停止/查看结果处理；进入 REVIEW 或取消后解除，不记录其他按键。Nowly 自身获得焦点时按 §7 的状态规则处理。

### 6.3 手动与自动滚动

**手动模式**

- 用户在指定目标内容区域使用滚轮/触控板滚动，Nowly 对稳定且有重叠的帧执行拼接。
- 停下来不会自动结束；可继续滚动，或点击“停止”进入结果确认。
- 向上回看不删除已采集内容，也不重复追加；回到已确认末端附近、重新建立连续重叠后才继续追加。
- 滚动过快、跳页或大段内容无重叠时暂停，提示回到最后已匹配内容附近；不根据速度猜测缺失内容。

**自动模式**

- 只有用户选择自动并点击开始后，才向已绑定的原生目标/滚动位置发送滚动输入。
- 每次输入前校验窗口身份、位置、前台归属及会话有效性；窗口句柄复用或目标切换不能继承旧输入权限。
- 等待稳定帧、匹配成功后再推进下一步，滚动步长以保留足够重叠为目标，不用固定高频滚轮覆盖所有应用。
- 用户切换应用、操作停止按钮、按 Esc、目标被遮挡或采集暂停时，立即停止新输入；不能等拼接队列清空才停。
- 不通过提升 Nowly 权限来操作更高完整性窗口；失败提示“自动滚动不可用，可切换手动滚动”，保留已截内容。
- 连续无新增内容可以触发暂停，但文案只能是“未检测到新增内容，可能已到底或目标无法继续滚动”，不能无证据宣称已完整截到底。

### 6.4 拼接质量和停止策略

- 自动排除滚动条、固定头尾/侧栏、少量动态区域对位移匹配的干扰；固定头尾在最终图中最多保留一次，不能作为每帧的重复接缝。
- 单色区域、重复列表项、动态视频、懒加载、虚拟列表不能只根据“图像相似”直接判定正确。
- 拼接器必须输出可诊断的匹配结果、接受/拒绝原因、置信信息、实际位移及停止原因。阈值由验证集标定，不把某个第三方默认数值直接当可靠性证明。
- 无可靠连续性时保留最后已确认的像素范围，进入 SCROLL_PAUSED；未确认的新帧不得偷偷加入最终图。
- 暂停后提供“继续”“查看已截部分”“取消长截图”。查看进入 SCROLL_REVIEW，由用户在该状态明确“使用已截部分”；继续必须重新找到末端重叠，不能从未知位置跳接。
- 目标移动/缩放、显示器变化或捕获失效后停止采集；若旧坐标不再可靠，不提供原地继续，只保留部分结果或返回普通截图的可用路径。
- 长图采集不自动拉回目标应用原滚动位置，避免再次输入改变应用；结果确认界面说明“原应用保留当前滚动位置”。
- 点击“停止”或 Esc 进入 SCROLL_REVIEW；拼接预览必须允许缩放和查看接缝，然后明确“使用长图”或“取消长截图”。
- 有拒绝帧、容量上限或异常停止时，确认动作改为“使用已截部分”，显示原因；不向 PNG 内插入警告水印。
- 取消长截图丢弃本次拼接，返回进入滚动前的普通截图选区；取消整次截图是另一个明确动作。

### 6.5 长图编辑和资源边界

- 确认长图后在同一编辑器展示，初始按宽度适配显示，最大 100%；允许 25%、50%、100%、200% 预览及垂直滚动，预览倍率不改变输出像素。
- 长图使用分块底图和可见范围渲染，不能创建与整张长图同高的单一 DOM/Canvas；标注坐标始终是长图原始像素坐标。
- 普通截图/长图统一的产品安全上限提案：总像素 64,000,000；任一边 65,535 像素；达到任一限制即拒绝继续扩大，绝不静默降采样。
- 会话内图像/标注/导出任务的显式分配预算为 512 MiB；无法在预算内进行下一步时预先拒绝。此预算不是整个 Tauri 进程 RSS 上限，也不是已测内存用量。
- STARTING 也适用同一预算：先读取显示器元数据，按每屏原始格式、捕获纹理、色彩转换 staging、预览副本和必要双缓冲估算峰值，再隐藏 Bar 和分配。按各屏分块存储，不先分配包含巨大桌面空隙的整幅虚拟桌面图。源屏幕总像素可以大于 64MP（该值限制输出），但若无法在预算内冻结所需全部来源屏幕，则在捕获前明确拒绝，不悄悄漏掉副屏或降低分辨率。
- 预览、撤销数据、待处理帧队列和导出临时缓冲均计入预算；采集队列采用有界队列和背压，不积压无上限帧。
- 预算不足时保留仍可安全导出的已确认内容；若复制路径需额外连续大缓冲而失败，允许改用分块 PNG 保存，明确提示，不能崩溃或复制缩小版冒充原图。
- 上述数值是待确认的产品限制和验证目标，不是浏览器/PNG 编码格式的固定极限。若 V08 证明不合理，回到规格审批调整，不由实现者私改。

## 7. 键盘与取消优先级

按键分发优先级：系统保存对话框 → 中文 IME 组合输入 → 文本控件 → 打开的属性弹层 → 当前绘制/拖动 → 已选标注 → 截图主状态。

| 操作 | 行为 |
|---|---|
| AIMING 的 Ctrl+C | 复制当前 HEX，保持 AIMING |
| SELECTING/正在绘制或拖动时 Ctrl+C | 不导出未提交内容，不修改剪贴板 |
| EDITING 且无文本焦点的 Ctrl+C | 复制最终图片，成功后结束会话 |
| 文本控件中的 Ctrl+C/X/V/Z/Y | 文本编辑自身处理，不复制图片、不改变全局标注历史 |
| SCROLL_PREPARE 的 Ctrl+C/Ctrl+S | Nowly 焦点下不复制色值/图片、不保存；已有文本选区的普通复制保留 |
| SCROLLING / SCROLL_PAUSED 的 Ctrl+C/Ctrl+S/Enter | 目标应用有焦点时全部归目标；Nowly 控制条有焦点时不导出，Enter 只操作当前焦点按钮 |
| SCROLL_REVIEW 的 Ctrl+C/Ctrl+S | 确认采用结果前不导出；不能绕过“使用长图/使用已截部分” |
| SCROLL_PREPARE / SCROLL_REVIEW 的 Enter | 只执行当前焦点按钮；画布空白焦点不隐式开始/确认 |
| EDITING 的 Ctrl+S | 提交有效草稿后另存 PNG；IME 组合输入未结束时不触发保存 |
| 无局部编辑且画布拥有焦点的 Enter | 复制图片并完成；焦点在按钮上时保留按钮自身键盘语义 |
| 文本中的 Enter / Ctrl+Enter | 换行 / 提交文本 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 非文本编辑时，撤销 / 重做 / 重做已提交标注 |
| Delete / Backspace | 画布焦点下删除所选对象；文本控件保留原语义；不导航后退 |
| 箭头键 | 选择工具、画布焦点且无标注时移动选区 1 个物理像素；有对象选中时移动对象 |
| Shift+箭头键 | 对上述移动改为 10 个物理像素 |
| Alt+箭头键 | 无标注选区调整右/下边界 1 个物理像素；最小 1×1 |
| `[` / `]` | 选择工具且画布焦点时，按创建顺序循环选择上一个/下一个标注；未选中时分别从末个/首个开始，播报类型与序号 |
| 已选文字对象的 Enter | 进入该对象的文字编辑，不完成截图；其他对象属性通过 Tab 进入工具属性控件 |
| Tab / Shift+Tab | 遍历截图工具和可访问控件，覆盖层内正常焦点管理 |
| Esc | 按以下层次执行，单次只消耗一层 |

Esc 的层次：

1. 交给保存对话框或正在组合输入的 IME。
2. 取消本轮文本编辑；或关闭当前属性弹层。
3. 取消当前未提交绘制/拖动，恢复动作前状态。
4. 取消对象选择。
5. SCROLL_PREPARE → 原普通截图 EDITING；SCROLLING/SCROLL_PAUSED → SCROLL_REVIEW；SCROLL_REVIEW → 丢弃长图、恢复原普通截图 EDITING。任何 Esc 路径都不能自动恢复滚轮输入，重新采集必须明确点击“开始/继续”。
6. AIMING 或无上述局部上下文的 EDITING：取消整次截图，不修改剪贴板、不写文件。

工具栏“取消”始终是明确放弃整个截图会话；丢弃临时截图不增加确认弹窗。保存文件覆盖仍必须有系统确认，不能把截图取消规则套用到磁盘覆盖。

工具栏提供键盘操作说明；`[`/`]` 仅在非文本、非 IME、画布焦点时生效。创建自由笔等空间绘制仍需要指针，本规格保证工具可达和已有对象可选择/编辑，不宣称全部绘制操作都能无指针完成。

导出事务期间采用 §8.1 的专门取消规则：编码时取消的是本次导出并返回编辑；最终提交不可回滚时取消控件暂不可用，不能承诺撤回已写入的系统剪贴板或文件。

## 8. 复制、保存、失败与隐私

> 截图历史功能修订：以下原始设计中的“原生另存为”“复制不落盘”及排除历史/全局快捷键的限制已由新需求取代。截图按钮直接启动截图，不显示菜单；截图历史通过独立全局快捷键打开，设置提供全局快捷键（默认 Ctrl+Alt+A / Ctrl+Alt+H）。复制和保存均先归档最终 PNG 到系统图片目录的 `Nowly\Screenshots`，保存不再弹对话框，取消不归档。历史采用独立窗口、SQLite 元信息索引及可重建缩略图缓存；删除须确认并同步删除原图。归档失败保留编辑界面且不执行复制；归档成功但复制失败时保留历史，重试相同图片复用记录。只保存最终处理结果，不保存未脱敏底图。使用说明以 README 为准。

### 8.1 复制

- 导出先合成底图、普通标注、马赛克，输出不包含边框、控制点、工具栏、光标或预览提示。
- 写入 Windows 标准图片剪贴板格式，必要时同时提供 PNG 与标准位图格式，确保已验收的微信、画图、Word 能按图片粘贴；不能只写图片路径或 Base64 文本。
- 复制图片只在写入成功后关闭会话；失败保留选区和全部标注，完成按钮旁显示“复制失败，请重试或保存图片”。
- 导出期间冻结本次版本，禁用重复完成/保存，显示静态“正在复制…”或“正在保存…”；成功回调必须校验会话/版本。
- 编码/准备缓冲阶段，Esc 或“取消导出”中止本次输出并回到 EDITING，保留标注且清理本次临时文件；写入前必须再次检查取消和版本。进入实际剪贴板写入/文件替换的短暂提交阶段后，取消控件禁用并显示“正在完成…”，以提交的真实结果决定成功退出或失败返回，不伪称已经撤回副作用。
- 剪贴板被占用可做有界重试，超过时限后返回可重试错误，不无限阻塞 UI。正常取消不改剪贴板；写入 API 的部分失败不能保证还原旧剪贴板，应如实报错。

### 8.2 保存

- 原生“另存为”对话框；默认文件名 `Nowly-截图-YYYYMMDD-HHmmss.png`；中文/空格路径有效。
- 初始目录为系统图片目录；没有可用目录时使用系统保存对话框默认位置，不新建截图历史目录。
- 用户取消对话框时完整返回编辑器。保存失败显示在保存控件旁，不关闭会话。
- 同名文件覆盖需系统确认；实际写入使用同目录临时文件和成功后的替换策略，失败不能留下半写目标或损坏原文件。
- 原生保存对话框返回的目标须绑定本次导出的一次性授权/原生路径身份；在创建临时文件和提交时检查目录/目标是否被替换。正常目录链接可以解析后使用，但不能跟随在授权后被更换的 junction/symlink 写入另一个目标。目标身份变化或文件系统无法满足安全提交语义时，不执行覆盖，返回编辑器并提示重新选位置；不能假定本地 NTFS、可移动盘和网络卷具有相同替换保证。
- 保存 PNG 只写合成后的像素与必要颜色信息，不写窗口标题、应用名、桌面坐标、文件来源路径或未遮挡原始图。
- 保存成功后结束截图，不额外复制图片。成功文件属于用户，不随会话清理删除。

### 8.3 隐私与错误信息

- 不上传、不自动进入附件库、不创建截图历史、不向模型发送屏幕内容。
- 不记录像素、色值采样轨迹、窗口标题、用户保存路径或输入内容；诊断仅记录脱敏的错误类别、性能/容量计数与版本。
- 仅在显式保存时创建图像临时文件；正常结束清理应用确知归属的临时文件。崩溃恢复仅处理有精确所有权记录的临时文件，禁止按宽泛目录/文件名模式删除用户数据。
- 结束后释放本会话底图、标注及拼接缓存；不宣称能物理擦除操作系统内存或清除其他应用已读取的剪贴板。
- 图片/色值写入系统剪贴板后，系统剪贴板历史、云剪贴板及其他应用可能读取，不能宣传为“只有 Nowly 可见”。
- 受保护内容不可捕获时提示限制；不能只因图像全黑就判失败，合法黑色内容仍须允许输出。
- 开始截图失败发生在覆盖层显示前时，恢复 Bar，在原截图按钮附近提供静态错误；不能通过打开 AI/状态详情来代替错误反馈。

## 9. 架构边界与接入点

| 单元 | 唯一职责 | 不能承担 |
|---|---|---|
| Bar 截图入口 | 发起/显示启动失败反馈 | 不扩成全屏，不复用 AI/提醒确认动作 |
| Rust CaptureSession | 状态机、会话身份、Bar 临时抑制、恢复与取消 | 不持久化截图历史、不改变提醒业务状态 |
| CaptureBackend | 显示器/目标识别、帧与色彩标准化 | 不处理 UI 点击或标注业务 |
| ScreenshotOverlay | 取色放大镜、选区、工具栏、键盘交互 | 不直接读取任意桌面/路径，不创建第二会话 |
| AnnotationDocument / Renderer | 标注模型、历史、预览与分块输出的一致性 | 不通过 DOM 截图替代真实图像输出 |
| ScrollCaptureSession / Stitcher | 目标绑定、输入协调、稳定帧、拼接/拒绝/部分结果 | 不向未绑定应用继续输入，不猜接缝 |
| OutputService | 剪贴板、系统路径选择、PNG 编码与安全写入 | 不上传、不进入内部附件表 |

接入依据（当前代码）：

- `src-tauri/src/screen_capture.rs`：**已存在的接缝**。Bar 的截图按钮调用 `start_screen_capture`；本文实现时替换其函数体与 `is_available`，调用方不需要改动。
- `src/main.tsx`：需要为专用截图窗口 label 增加明确的前端路由。
- `src/app/layout/StatusIsland.tsx`、`src/app/layout/BarButtonLane.tsx`、`src/quick-panel/StatusIslandApp.tsx`：应用按钮车道与命令分发已存在；截图仍需原生会话事件。
- `src/app/bar-buttons.ts`：应用目录与持久化值的归一化。
- `src-tauri/src/quick_panel.rs`：显示器、缩放、可见区域与定位（已按应用按钮数计算）；原生监视器需识别截图抑制状态。
- `src-tauri/src/status_island.rs`：现有常驻模式隐藏限制不能直接当截图隐藏实现。
- `src-tauri/src/main.rs`：失焦处理、窗口生命周期及命令注册。
- `src-tauri/capabilities/default.json`：现有只覆盖主窗口和 Bar；新增截图窗口使用单独最小权限配置。
- `src/components/icons.tsx`、`scripts/generate-icons.mjs`：Bar 按钮的 `Crop` 已补齐；截图工具栏图标仍需补齐。

数据/权限约束：

- Rust 是会话、原始帧和目标身份的权威；每个敏感命令核查调用窗口 label、会话 ID、状态及参数边界。
- 窗口 capability 是一层防线，不能替代命令内部的会话/来源校验。截图窗口不获得业务数据库、AI 配置或任意文件系统权限。
- 截图页仅装载本地可信资源，不接收远程页面来调用抓屏命令。
- 截图窗口有专用导航、弹窗及出站请求限制：仅允许应用必需的本地资源/IPC/有界图像通道，阻止 HTTP(S) fetch、WebSocket、表单及远程图片等外发。需通过 CSP 或原生 WebView 网络策略证明阻止能力，而非仅观察正常流程未联网；不把此策略粗暴套用到现有 AI 主窗口。
- 像素使用有界二进制/分块通路，不能逐帧用巨大 Base64/JSON invoke，也不能每次鼠标移动跨进程取一张屏幕。
- 一个版本化标注模型和一致的渲染规则同时服务预览与输出。字体、文字换行、裁剪、马赛克网格、色彩转换需通过 V05/V09 验证，不能假设 Rust 和 WebView 的文字渲染自动相同。
- 滚动捕获期间只有该目标区域所需的新帧被处理，不将窗口标题或截图数据送给现有 AI。
