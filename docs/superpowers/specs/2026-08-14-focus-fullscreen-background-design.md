# 专注全屏暖白背景设计

## 目标

将全屏专注层从透明改为完全不透明的暖白静态背景，遮挡桌面杂乱内容，同时保持 Nowly 明亮、温暖、柔和的视觉语言。

## 视觉设计

- 基础背景使用 `#F8F6F2`。
- 右上放置大型浅青实心圆 `#DDF8FC`。
- 左下放置青绿色细线圆，边框 `#B9E9F0`。
- 左上区域放置小型暖黄实心圆 `#FDF4D6`。
- 所有图形为静态纯色，不使用渐变、图片、玻璃模糊、噪点、动画或过渡。
- 倒计时使用 `#211F1C`，状态说明使用 `#716D66`，品牌说明使用 `#8E887A`。
- 次操作为白色表面、默认边框和深色文字；主操作继续使用青绿色。
- 装饰层使用 `aria-hidden`，不拦截指针，不进入焦点或阅读顺序。

## 交互与状态

计时、暂停、结束、Esc 退出、控制区显示隐藏、系统通知和统计逻辑保持不变。完成状态沿用同一背景，只更新状态文案和操作。所有状态即时切换，继续遵守项目全局禁用动效规则。

## 验收

- 全屏专注层计算背景色为 `rgb(248, 246, 242)`，不再透明。
- 背景不存在 `linear-gradient` 或 `radial-gradient`。
- 三个静态装饰图形颜色与位置正确。
- 倒计时和状态文字符合 `design.md` Token。
- 现有全屏专注组件测试和 Playwright 测试通过。
