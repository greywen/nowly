# 时间模块设计规格

日期：2026-10-11
状态：用户已审阅并批准，进入实现阶段。

## 目标与范围

新增可从模块选择器添加的独立时间模块，不改变现有默认布局。桌面以简洁时钟组件呈现，单个模块可排列多个时区；不在桌面放置标签页、闹钟列表、时差工具或常驻业务工具栏。所有配置与工具集中在时间设置弹窗。遵守根目录 design.md；借鉴苹果桌面组件的简洁排布，不复制其视觉体系。

第一版：多时区、纯时间 / 纯指针 / 混合、自适应、时差对照、独立闹钟与重复规则、Nowly Bar 通知。排除秒表、通用倒计时、铃声、应用退出后的系统调度。

## 桌面展示

- 一个时间模块内显示多个时钟，使用 IANA 时区标识，不以固定 UTC 偏移代替时区；默认仅一个跟随电脑的本地时钟。
- 每个时钟独立选择纯时间（只有数字）、纯指针（只有表盘）、混合（表盘与数字）。
- 城市、日期、时差默认隐藏，可分别开启；允许城市别名、排序与移除。至少保留一个时钟。
- 支持 12/24 小时与显示秒；12 小时制保留 AM/PM 防止歧义。视觉隐藏城市不移除可访问名称。
- 指针按秒离散更新，不使用 CSS 或 JS 平滑补间；数字使用表格数字与既有字号范围。
- 布局根据模块宽高、数量、模式自适应，表盘与数字不裁切、不重叠。优先减少列数/缩放表盘/隐藏可选信息；达到可读下限后只让模块正文滚动，不缩小到规范以下字号。
- 不常驻模块标题或配置操作。设置接入现有布局管理入口，并提供可访问的配置入口；壁纸态不因查看时钟抢占焦点。

## 时间设置与时差对照

设置弹窗使用项目既有对话框、下划线标签页与控件，包含时钟、时差对照、闹钟三个设置区域。世界时区可搜索选择，非法或环境不支持的时区显示明确错误，不静默以本地时间替换。

时差对照以本地日期时间为基准，转换为同一个瞬时点后展示所有配置时区的日期、时间、UTC 偏移及跨日关系；支持回到现在。对照不会改变桌面实时时钟，也不会自动建立日历日程。

## 闹钟

- 独立模型，不写入日历事件；所有闹钟跟随电脑当前本地时区。
- 字段包括 ID、标题、时分、重复规则、一次性日期、启用状态、创建/更新时间。重复支持一次性、每天、周一至周五、自选星期；自选星期不能为空。
- 新建、编辑、启停、删除；清楚展示下次触发时刻；一次性不能创建在过去，触发或错过后自动停用。
- 每日重复按当地墙上时间而非每隔 24 小时计算。夏令时重复小时只提醒一次，跳过时间计入错过记录；系统时区改变后重新计算未来触发，不重复发送已处理的当地日期实例。
- Rust 后台负责持久化调度，与 React 可见性、模块添加移除和设置窗口开关无关。
- 到点进入 Nowly Bar 提醒队列；不抢占已打开的功能菜单、AI 或截图历史。确认仅消费对应闹钟实例，不改变日程或专注提醒。
- 稍后 5 分钟针对当前实例，使用绝对到期时间持久化，不改重复规则；确认与稍后操作幂等。
- 不额外播放铃声。完全退出后不触发；托盘/后台运行时正常触发。

## 离线与恢复

保存调度检查点与实例处理记录。首次启用调度只从当前时刻开始，不生成创建前的错过历史；新建/启用/编辑重复规则后也不补算生效前实例。

正常运行按后台检查周期触发到期实例。发现启动或休眠恢复间隔时，将间隔内未处理实例统一登记为错过，并发送一个汇总通知，而非逐条补发。汇总显示总次数、涉及闹钟及时间范围；确认后持久化为已读，不因再次启动重复出现。较长离线期间以规则计算次数/范围，不生成无界实例数组。不自动把错过的闹钟改为稍后提醒。

数据库事务保证调度检查点与实例登记一致；并发检查、系统时间回拨、重复 Bar 操作不得重复分发。发送失败保留可重试状态，不丢弃记录。

## 架构与持久化

- 前端时间工具层：可注入时钟、格式化、时区校验、时间换算、表盘角度等纯逻辑。
- 前端展示层：纯展示时间组件与共享节拍，隐藏时暂停界面刷新，恢复立即读取真实时间。
- 前端设置层：独立设置与时差对照、闹钟编辑；沿用 repository abstraction 与测试内存实现。
- Rust 存储层：增量 SQLite migration、新增时钟配置、闹钟、调度状态/实例记录，不破坏原有布局、设置与日历。
- Rust 调度层：本地时间规则、下次发生计算、检查点、错过汇总、确认与稍后；可注入当前时刻进行测试。
- Bar 集成层：扩展现有 snapshot/事件协议与提醒来源，兼容日程、专注与其他来源，保持菜单互斥和现有窗口形变。
- 中英文文案、README 功能说明直接更新；不增加无关依赖或重构现有模块。

## 错误与可访问性

加载失败使用静态错误与重试，不把失败显示为成功保存。保存失败保留草稿并提供反馈；无效时间、空星期、非法时区和已删除闹钟操作均校验。设置支持 Esc、焦点陷阱和归还；组件完整可访问名称不依赖城市可见，读屏不每秒播报。提醒操作可键盘使用。

## 验收

1. 新模块可添加、移动、缩放、移除，配置重启后保留；默认布局与原有模块保持不变。
2. 三种模式均支持一到多个时区；关闭辅助信息时确实只剩数字、表盘或两者。
3. 最小/常规/大尺寸与不同密度下无重叠、裁切；可选信息隐藏与正文滚动符合规则。
4. 12/24 小时、秒开关、非整数时差、跨日、夏令时、无效时区与恢复刷新有前端测试。
5. 闹钟四种重复规则、禁用/删除/编辑、下次触发、一次性停用、夏令时、回拨、时区变化、离线汇总、幂等、稍后持久化有 Rust 测试。
6. Bar 能区分闹钟/错过汇总与原有提醒；不抢占 AI/菜单/历史，不误消费其他来源；有协议/组件测试。
7. 构建、针对性 Vitest、Rust 测试通过；Playwright 验证纯展示、自适应与设置流程。Windows 真机验证托盘运行、休眠恢复与 Bar 提醒，不能以浏览器模拟代替原生验证。
