# 快捷面板顶部抽屉设计

## 目标

将快捷 AI 窗口改为从屏幕顶部覆盖展开的完整聊天抽屉，并在设置中提供快捷窗口开关与快捷键配置。

## 方案

继续使用 Tauri 独立 `quick-panel` 窗口，不显示 Nowly 主窗口。窗口保持无边框、置顶和居中，前端通过抽屉容器表达顶部展开状态。由于 Nowly 设计规范禁止补间动画，打开和关闭使用即时状态切换；“下滑”通过窗口贴顶和内容布局实现，不使用 CSS transition 或 animation。

快捷面板由 `QuickPanelHost` 负责窗口级状态与面板路由，AI 面板复用现有 `AssistantDock` 业务逻辑。未来面板只需注册新的 `QuickPanelId` 和内容组件。

## 设置

在设置的界面/导航区域加入快捷窗口设置：

- 启用/停用快捷窗口；
- 录入快捷键；
- 默认值为 `Ctrl+Space`；
- 空快捷键或无法解析时拒绝保存；
- 保存后由 Rust 重新注册快捷键；
- 注册冲突时保留旧快捷键并显示简洁错误。

## 关闭与安全

- 再次快捷键、Esc、失焦均隐藏快捷窗口；
- 隐藏不丢弃草稿和聊天状态；
- 快捷窗口允许调用既有 AI IPC，但不放宽业务动作、确认和撤销边界；
- 主窗口保持隐藏，不切换壁纸/前台模式。

## 验证

- React 单元测试覆盖快捷键配置解析、抽屉状态和设置保存；
- 生产构建与全量 Vitest；
- Rust `cargo check`；
- Windows 桌面实测快捷键注册、窗口置顶、失焦关闭和语音输入。
