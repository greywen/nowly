# Nowly Good 设计系统原型重设计规格

日期：2026-07-29

## 1. 目标

依据项目根目录 `design.md`，重新设计 `docs/prototypes/nowly-final-uiux.html`，使该单文件原型完全采用 Good 1.1.4 当前默认浅色主题的设计 Token，同时保留 Nowly 单屏桌面效率面板的信息架构与展示级交互。

本规格只重构独立 HTML 原型，不修改 React/Tauri 产品代码。

## 2. 规范优先级

1. 根目录 `design.md` 是本次视觉实现的唯一权威规范。
2. 本规格负责确定原型范围和信息架构。
3. 旧版原型及旧版设计规格只用于确认功能入口，不作为颜色、字体、间距或组件样式依据。
4. 删除旧蓝色体系 `#009EF7`、`#181C32`、`#7E8299` 及所有同类旧 Token。

## 3. 保留范围

原型保留以下结构和展示级交互：

- 顶部状态栏。
- 月历主卡片。
- 四象限优先事项卡片。
- 便签卡片。
- 日期详情弹窗。
- 日程编辑弹窗。
- 任务编辑弹窗。
- 便签编辑弹窗。
- 设置弹窗。
- 月份标题切换。
- 任务完成状态切换。
- 设置分类切换。
- 原型控制器与重置状态。
- 弹窗焦点进入、焦点循环、Esc 关闭、遮罩关闭和焦点归还。

所有交互仍为内存中的展示状态，刷新页面恢复初始状态。

## 4. 删除范围

删除以下旧设计和功能：

- 桌面融合背景模式。
- 背景模式切换按钮。
- 设置弹窗中的背景模式与卡片透明度选项。
- 所有径向渐变、线性渐变和抽象桌面壁纸背景。
- 所有 `backdrop-filter` 和玻璃拟态表面。
- 所有 CSS `transition`、`animation` 和平滑滚动。
- 所有 hover 位移、缩放、阴影抬升及弹窗淡入效果。
- 8–12px 的不可读界面文字。
- 普通卡片的厚重阴影。

## 5. 页面架构

```text
Nowly prototype
├─ 70px 白色 Header
│  ├─ 品牌与日期信息
│  ├─ 今日摘要
│  ├─ 设置
│  └─ 设为壁纸
├─ 暖灰页面内容区
│  ├─ 月历卡片
│  └─ 右侧栏
│     ├─ 优先事项卡片
│     └─ 便签卡片
├─ 原型控制器
└─ 弹窗层
   ├─ 日期详情
   ├─ 日程编辑
   ├─ 任务编辑
   ├─ 便签编辑
   └─ 设置
```

页面继续占满 `100vw × 100vh`，禁止页面级滚动；只允许卡片指定内容区和弹窗 Body 内部滚动。

## 6. 视觉系统

### 6.1 页面与表面

- 页面基础背景：`#F8F6F2`。
- Header、卡片、弹窗：`#FFFFFF`。
- 次级分区：`#F6F1E9` 或 `#F9F9F9`。
- 普通边框：`1px solid #EAEAEA`。
- 标准圆角：`15.2px`。
- 普通卡片阴影：`none`。
- 浮层只使用 `design.md` 定义的阴影。

### 6.2 颜色

- 主色：`#4FC9DA`。
- 主色激活：`#30A6B6`。
- 主色浅背景：`#DDF8FC`。
- 主文字：`#211F1C`。
- 强正文：`#403D38`。
- 次级正文：`#716D66`。
- 弱文字：`#968E7E`。
- 成功：`#B8D935`。
- 信息：`#4F55DA`。
- 警告：`#E8C444`。
- 危险：`#F06445`。

### 6.3 字体

使用：

```css
Inter, "Microsoft YaHei", "PingFang SC", Helvetica, Arial, sans-serif
```

- 页面标题：`21.6–24px / 700`。
- 卡片标题：`18.4–20px / 600–700`。
- 正文：`16px / 400 / 1.5`。
- 次级正文和按钮：`15.2px / 500–600 / 1.5`。
- 辅助文字：`13.6px / 400–600 / 1.5`。
- 不使用低于 `13.6px` 的可见界面文字。

### 6.4 间距

- 采用 4px 基础网格。
- 桌面内容区内边距优先 `24–36px`，受固定视口高度限制时只使用规范刻度缩减。
- 主模块间距：`24px`；1366×768 紧凑模式使用 `16px`。
- 标准 Card Header 高度：`70px`。
- 标准 Card Header 水平内边距：`36px`。
- 标准 Card Body：`32px 36px`。
- 固定视口紧凑卡片可使用 `20–24px`，同级组件保持一致。

## 7. Header

Header 高度为 `70px`，白色背景，下边界 `#EAEAEA`，默认无阴影。

左侧包含：

- Nowly 品牌标记。
- 当前日期 `2026 年 7 月 23 日，星期四`。
- 今日摘要。

右侧包含：

- 设置图标按钮。
- “设为壁纸”主按钮。

不再显示时间作为 44px 超大标题，不显示桌面融合入口。Header 在小尺寸下隐藏今日摘要中的非关键信息，但不缩小文字到规范以下。

## 8. 月历卡片

月历继续作为最大内容区域。

Card Header 包含：

- 月份标题。
- 本月日程数量标签。
- 上一月、今天、下一月按钮。
- 新建日程主按钮。

月历规则：

- 星期标题使用 `13.6px`。
- 日期数字使用 `13.6px` 或 `15.2px`。
- 日程文字使用 `13.6px`。
- 日期格使用 `#EAEAEA` 分隔。
- 周末使用 `#F8F6F2` 弱背景。
- 非当前月日期使用 `#B5B0A1`。
- 今天使用 `#DDF8FC` 背景、`#4FC9DA` 边框和实心主色日期标记。
- 日程按功能色浅背景呈现，并同时包含文本，不只依靠颜色。
- 1366×768 下通过减少单日展示日程数量和隐藏“还有 N 项”等次要信息控制高度，不降低字号。

## 9. 优先事项卡片

保留 2×2 四象限布局：

- 重要且紧急：危险浅背景 `#FFF0ED`。
- 重要不紧急：主色浅背景 `#DDF8FC`。
- 不重要但紧急：警告浅背景 `#FDF4D6`。
- 不重要不紧急：中性背景 `#F8F6F2`。

每个象限包含标题、数量、任务标题和截止说明。标题不低于 `13.6px`，任务正文使用 `13.6–15.2px`。完成状态使用勾选、删除线和降低文字权重共同表达。

## 10. 便签卡片

保留两条便签和查看全部入口。便签表面使用规范浅色：

- 黄色便签：`#FDF4D6`。
- 主色便签：`#DDF8FC`。

便签标题使用 `15.2px / 600`，摘要和时间使用 `13.6px`。便签自身不增加阴影或 hover 位移。

## 11. 按钮与表单

- 标准按钮圆角：`15.2px`。
- 标准按钮：`16px / 500`，内边距 `12.4px 24px`。
- 小按钮：`15.2px / 500–600`，内边距 `8.8px 16px`。
- 主按钮：`#4FC9DA` 白字，active 为 `#30A6B6`。
- 次按钮：`#F8F6F2` 背景、`#403D38` 文字。
- 图标按钮：`35×35px` 或 `40×40px`。
- 表单高度：`44–48px`。
- 输入框圆角：`15.2px`。
- 输入边框：`#EAEAEA`。
- focus-visible：`0 0 0 4px rgba(79,201,218,.25)`。
- 删除操作使用明确危险按钮样式，不使用内联颜色。

## 12. 弹窗

所有弹窗遵循：

- 白色表面。
- `1px solid #EAEAEA`。
- `15.2px` 圆角。
- `shadow-lg`。
- 遮罩 `rgba(0,0,0,.20)`。
- Header、Body、Footer 水平内边距统一为 `32–36px`。
- Header 和 Footer 使用 `#EAEAEA` 分隔。
- Header、Footer 固定，Body 内部滚动。
- 无任何显示或关闭动效。

设置弹窗的“外观”页调整为：

- 信息密度。
- 周起始日。
- 是否显示周末。
- 日期格式。

不再提供背景模式与透明度。

## 13. 原型控制器

原型控制器默认折叠，放置在右下角：

- 折叠按钮采用次级按钮风格。
- 展开面板使用白色表面、规范边框、`15.2px` 圆角和 dropdown 阴影。
- 显示与隐藏即时切换。
- 保留五类弹窗预览和状态重置入口。

## 14. 响应式规则

### 14.1 支持范围

- 最小支持视口为 `1366×768`。
- 宽度和高度均不设置最大上限。
- 页面始终使用完整可用视口，不设置固定 `max-width` 或 `max-height` 容器。
- 低于 `1366×768` 不属于本原型的验收范围。

### 14.2 1366×768

- 内容区内边距和模块间距使用 `16px`。
- Header 仍为 `70px`。
- 隐藏非关键摘要或次要日程，不降低文字到 `13.6px` 以下。
- 卡片紧凑内边距使用 `16–20px`。
- 右栏内部可滚动，页面本身不得滚动。
- 日历日期格至少保持日期与一条关键日程可读。

### 14.3 1920×1080

- 主内容区使用 `24px` 间距。
- 日历与右栏维持约 `1.6 : 0.72`。
- 卡片保持舒适内边距。
- 日历单元格展示最多 2–3 条日程。

### 14.4 超大视口

- 主内容区随视口持续流式扩展，不设置内容最大宽度或高度。
- 日历与右栏保持约 `1.6 : 0.72` 的列比例，避免右栏被固定为过窄宽度。
- 卡片高度随可用视口增长，日历格和模块获得更多留白。
- 字号、控件尺寸和信息数量仍遵循 `design.md`，不因屏幕增大而无限放大或无限增加内容。
- 页面外边距最多保持规范的 `36px`，额外空间分配给主内容，而不是形成大面积空白边缘。

## 15. 动效禁令

全局应用：

```css
*,
*::before,
*::after {
  animation: none !important;
  animation-duration: 0s !important;
  transition: none !important;
  scroll-behavior: auto !important;
}
```

页面不得包含 CSS 或 JavaScript 动画、平滑滚动、自动轮播、Spinner、Skeleton shimmer、hover 位移、缩放、弹窗淡入和背景模糊。

## 16. 无障碍

- 保留语义化 Header、Main、Section、Aside、Dialog 和表单标签。
- 图标按钮提供 `aria-label`。
- 状态不只依靠颜色表达。
- 所有主要操作可通过键盘访问。
- 焦点状态清晰可见。
- 弹窗保留焦点循环、Esc 关闭和焦点归还。
- 隐藏次要内容时不破坏可操作元素的语义与焦点顺序。

## 17. 验收标准

1. 原型通过本地 `file://` URL 可直接打开，无网络依赖。
2. 视觉颜色完全来自 `design.md`，不存在旧版蓝色 Token。
3. 页面没有渐变、桌面融合、玻璃拟态或背景模糊。
4. 普通卡片统一为白底、`1px #EAEAEA` 边框、`15.2px` 圆角、无阴影。
5. 可见界面文字不低于 `13.6px`。
6. 按钮、输入框、导航、标签和弹窗符合 `design.md`。
7. 页面不存在 `transition`、运行中的 `animation`、平滑滚动或 JS 动画。
8. 从最小 `1366×768` 到任意更大视口均无页面级水平或垂直滚动，且不存在限制内容扩展的最大宽高。
9. 月历、四象限和便签在主界面同时可访问。
10. 五类弹窗均可打开、关闭并保持键盘焦点行为。
11. 原型控制器和重置行为可用。
12. 页面功能状态切换即时生效。
