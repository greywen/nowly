# 日历添加/编辑表单无框紧凑版设计

## 目标

优化日历添加与编辑表单的信息密度和操作效率，解决现有版本纵向过长、区块卡片过多、左右空间失衡的问题。保留现有创建、编辑、删除、重复日程、提醒、远程日历、校验和富文本备注能力。

## 已确认布局

表单采用连续式单页结构，不再为时间、备注和设置分别添加外层卡片框。各区域仅通过留白和 `1px` 分隔线建立层级。

从上到下的顺序：

1. 标题与目标日历。
2. 时间范围。
3. 备注。
4. 提醒与分类颜色。
5. 折叠的重复及更多设置。

弹窗 Header 和 Footer 保持固定语义，Footer 保留取消、保存以及编辑状态下的删除操作。

## 组件与交互

### 标题和日历

- 标题为主要输入，占据剩余宽度。
- 创建日程且存在可写远程日历时显示目标日历选择器。
- 编辑状态、无可写远程日历和远程日历规则保持现有逻辑。

### 时间范围

- 将四个独立日期、时间字段组合为一个时间范围区域。
- 开始端和结束端各显示日期与时间，二者之间使用方向提示。
- 继续复用现有 `DatePicker` 与 `TimePicker`，不改变日期和时间存储格式。
- 保留全天事件开关；全天时隐藏时间选择。
- 提供快捷时长入口：30 分钟、1 小时。选择后只调整结束时间。
- “今天下午”“明天”等依赖当前日期语义的快捷项暂不实现，避免引入不明确的数据修改。

### 备注

- 继续使用 `RichEditor`。
- 默认工具栏改为常用操作：粗体、斜体、列表、链接、图片或附件。
- 其余格式能力放入“更多”入口；若现有编辑器不支持可靠的分层工具栏，则保留完整功能，但通过更紧凑的工具栏布局呈现。
- 附件入口保留。

### 提醒

- 已选择的提醒显示为可移除标签，例如“10 分钟前”。
- 提供常用快捷项“10 分钟前”和“1 小时前”。
- “自定义”展开现有数值与单位控件。
- 继续遵守最多提醒数量和分钟数校验规则。

### 分类与颜色

- 分类选择与颜色选择合并到同一区域。
- 继续复用 `Select` 和 `ColorPicker` 的数据与校验逻辑。
- 分类与颜色仍是两个独立数据字段，不建立自动绑定关系。

### 重复及更多设置

- 默认折叠，并在折叠行显示当前摘要，例如“不重复”。
- 展开后显示现有重复预设和自定义重复规则。
- 如果已经配置重复规则、存在重复规则校验错误，或正在编辑重复日程，则默认展开。
- 远程目标不支持重复时维持现有隐藏逻辑。

## 响应式

- 桌面端时间范围为横向开始到结束。
- 窄屏下开始与结束垂直排列。
- 提醒与分类颜色桌面端双列，窄屏改单列。
- 不允许表单内容产生横向滚动。
- Footer 操作在小屏仍保持可见且不压缩到不可点击尺寸。

## 可访问性

- 所有现有 label、错误关联和键盘操作继续保留。
- 折叠区域使用原生按钮并提供 `aria-expanded`、`aria-controls`。
- 快捷时长与提醒快捷项必须有明确的可访问名称和选中状态。
- 不通过颜色单独传达分类或选择状态。

## 视觉约束

- 遵循根目录 `design.md`。
- 区域之间使用留白和 `#EAEAEA` 分隔线，不使用独立卡片边框。
- 输入控件继续使用暖灰背景、`15.2px` 圆角和现有焦点环。
- 不新增动画或 transition，展开与状态切换即时完成。
- 删除介绍性描述，只保留区块标题、字段标签、状态摘要和错误提示。

## 测试与验收

- 更新组件测试，覆盖新的 DOM 顺序、折叠状态、快捷时长和快捷提醒。
- 保留并运行所有现有 EventModal 创建、编辑、重复、提醒、远程日历和校验测试。
- 在桌面、820px 和 390px 宽度检查真实组件截图。
- 验证无横向溢出。
- 运行完整 `npm test`、`npm run build` 和 `git diff --check`。

## 非目标

- 不新增自然语言解析。
- 不修改后端日程数据模型。
- 不修改日历列表或日历视图。
- 不改变远程日历和重复日程的业务规则。
