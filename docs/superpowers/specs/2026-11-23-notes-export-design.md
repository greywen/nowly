# 便签导出

用户已确认 PDF、Markdown、批量勾选与全选、逐条文件加 ZIP，以及独立 worktree 实现。

- 全部便签管理器增加「导出」模式：原生复选框、全选、已选数量、PDF/Markdown 格式选择、执行和取消。
- 编辑已有便签时提供单条导出入口。导出当前草稿快照，不隐式保存、删除或修改便签。
- 没有附件的单条导出为 `.pdf` 或 `.md`。多条或含附件时导出一个 `.zip`，每条便签独立目录，正文和 `assets/` 同行；文件名清理 Windows 禁止字符并处理同名。
- Markdown 使用 GFM（标题、列表、任务清单、表格、代码、链接），提示颜色、字号和对齐等会简化。公式保留源码，视频保留链接。
- PDF 为可检索文字，使用 Windows WebView2 打印生成；图片嵌入、表格和长文分页。PDF 中的附件列表提示附带文件。外部图片不联网下载，改为明确的外部图片链接；视频不播放。
- 本地附件必须完整读取，缺失时整次导出失败而非静默丢失。附件原名用于显示，安全文件名用于 ZIP 路径；不泄露机器路径或 `attachment:`/`blob:` URL。
- 生成过程只读，显示静态逐条进度、禁止重复提交。取消系统保存对话框不是错误；失败保留选择以便重试。
- 原生保存命令只允许主窗口，输出限制为 PDF/Markdown/ZIP，通过系统另存为确认后写入同目录临时文件并原子替换。渲染窗口不可见，无 IPC 权限；导出 HTML 限制资源及脚本访问。
- 使用既有 Dialog、Select、Checkbox、按钮和 CSS Token，无新增动画，覆盖七种界面语言。
- 不包含备份恢复、PDF 合并、发布、安装包或原仓库合并。

验收：转换和打包单测、UI 多选/空选择/失败重试测试、Rust 校验与写入测试、类型检查及构建、浏览器流程、真实 WebView2 PDF 中文提取与渲染检查。
