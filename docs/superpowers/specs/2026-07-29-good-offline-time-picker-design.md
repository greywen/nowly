# Good 离线时间选择器设计规格

日期：2026-07-29

## 1. 目标

将 `docs/prototypes/nowly-final-uiux.html` 日程编辑弹窗中的原生时间输入替换为 Good Flatpickr Time Picker 风格的离线时间选择器。

参考页面：

`https://preview.keenthemes.com/html/good/docs/?page=forms/flatpickr`

Good 官方示例使用：

```js
flatpickr({
  enableTime: true,
  noCalendar: true,
  dateFormat: "H:i"
});
```

本原型不引入 Flatpickr 完整依赖，而是在单文件内复刻其时间输入视觉和必要交互。

## 2. 应用范围

只替换：

- 日程编辑弹窗中的“开始时间”。
- 日程编辑弹窗中的“结束时间”。

不修改：

- 日期选择器。
- 主界面月历。
- 日期详情中的时间文案。
- 任务、便签或设置弹窗。

## 3. 时间规则

- 使用 24 小时制。
- 小时范围：`00–23`。
- 分钟范围：`00–55`。
- 分钟步长：`5` 分钟。
- 内部值格式：`HH:mm`。
- 开始时间初始值：`14:00`。
- 结束时间初始值：`15:00`。
- “现在”使用固定演示时间 `09:40`，避免系统时间导致截图和测试不稳定。
- 本次不增加开始时间早于结束时间的业务校验。

## 4. 时间触发控件

结构与日期触发控件保持同一组件语言：

```html
<button
  class="input time-picker-trigger"
  type="button"
  data-time-picker
  data-value="14:00"
  aria-haspopup="dialog"
  aria-expanded="false"
>
  <span data-time-value>14:00</span>
  <svg class="icon" aria-hidden="true">...</svg>
</button>
```

样式：

- 高度：`48px`。
- 背景：`#F8F6F2`。
- 默认边框：透明。
- 打开状态边框：`#4FC9DA`。
- 圆角：`15.2px`。
- 水平内边距：`16px`。
- 时间文字：`16px / 400 / 1.5`，颜色 `#716D66`。
- 时钟图标：`18px`，颜色 `#8E887A`。
- Hover：背景 `#F6F1E9`。
- 整个控件均可点击。
- 不使用浏览器原生 `input[type="time"]`。

## 5. 共享时间面板

开始时间和结束时间共用一个时间面板实例。

面板结构：

```text
Time Picker Popup
├─ Header: 选择时间
├─ Value area
│  ├─ Hour stepper
│  ├─ Separator (:)
│  └─ Minute stepper
└─ Footer
   ├─ 清除
   └─ 现在
```

面板样式：

- 宽度：`280px`。
- 白色背景：`#FFFFFF`。
- 边框：无。
- 圆角：`15.2px`。
- 阴影：`0 0 50px 0 rgba(82, 63, 105, 0.15)`。
- 内边距：`16px`。
- 面板定位在当前触发控件附近，并限制在业务弹窗 Body 安全区域内。
- 面板不得覆盖业务弹窗 Header。
- 面板不得超出业务弹窗左右边界。

## 6. 小时与分钟步进器

### 6.1 布局

- 小时和分钟各占一列，中间显示冒号。
- 每列从上到下依次为：增加按钮、当前值、减少按钮。
- 当前值使用两位数字。

### 6.2 当前值

- 数字：`28px / 700 / 1.25`，颜色 `#211F1C`。
- 数字容器最小尺寸：`64×56px`。
- 背景：`#F8F6F2`。
- 圆角：`15.2px`。
- 小时和分钟分别提供可读名称。

### 6.3 增减按钮

- 尺寸：`35×35px`。
- 背景：`#F8F6F2`。
- 图标：`#716D66`。
- Hover：背景 `#F6F1E9`，图标 `#4FC9DA`。
- 小时增加从 `23` 循环到 `00`，减少从 `00` 循环到 `23`。
- 分钟以 5 分钟步长循环；`55` 增加到 `00`，`00` 减少到 `55`。
- 分钟跨越边界时不自动改变小时，保持两个步进器独立、行为可预测。

## 7. 快速列表

为提高选择效率，面板在步进器下方提供紧凑快捷时间：

- `09:00`
- `09:30`
- `12:00`
- `14:00`
- `15:00`
- `18:00`

规则：

- 使用 3×2 网格。
- 每项使用小型次级按钮。
- 当前时间项使用 `#DDF8FC` 背景和 `#30A6B6` 文字。
- 点击后更新当前字段并关闭面板。
- 快捷项仅为辅助，不限制用户通过步进器选择其他时间。

## 8. Footer

- 顶边界：`1px solid #F6F1E9`。
- 内边距：`12px 16px`。
- “清除”：将值置空，触发控件显示 `选择时间`，并关闭面板。
- “现在”：写入固定时间 `09:40`，并关闭面板。
- 两项均即时生效。

## 9. 交互

- 点击触发控件打开面板。
- 再次点击当前触发控件关闭面板。
- 点击另一时间字段时切换活动字段并读取其当前值。
- 同一时间只显示一个时间面板。
- 日期面板和时间面板互斥；打开其中一个必须关闭另一个。
- 点击面板外部关闭。
- `Esc` 关闭并将焦点返回触发控件。
- 点击快捷时间、“清除”或“现在”后关闭并归还焦点。
- 父级业务弹窗关闭时，时间面板同步关闭。
- 不写入 localStorage。

## 10. 键盘与无障碍

- 触发控件使用原生 `<button>`。
- 使用 `aria-haspopup="dialog"` 和 `aria-expanded`。
- 面板使用 `role="dialog"`，标题为“选择时间”。
- 小时和分钟数值分别使用 `role="spinbutton"`。
- 小时提供 `aria-valuemin="0"`、`aria-valuemax="23"` 和当前值。
- 分钟提供 `aria-valuemin="0"`、`aria-valuemax="55"`、`aria-valuenow` 和步长语义说明。
- `ArrowUp` / `ArrowDown` 调整当前聚焦的小时或分钟。
- `PageUp` / `PageDown`：小时按 6 小时调整；分钟按 15 分钟调整。
- Home：小时或分钟置为 `00`。
- End：小时置为 `23`，分钟置为 `55`。
- Enter：确认当前步进器时间，更新触发控件并关闭。
- Tab 可在小时、分钟、快捷时间、清除和现在之间移动。

## 11. 动效与依赖

- 不引入 Flatpickr CSS/JS。
- 不引入 jQuery、Moment.js、CDN 或网络资源。
- 不使用浏览器原生时间面板。
- 面板打开、关闭和数值变化即时生效。
- 不使用 transition、animation、滚动动画或数字翻转效果。
- `file://` 直接打开必须完整可用。

## 12. 设计规范更新

在 `design.md` 的日期选择器后新增“时间选择器”章节，记录：

- Good Solid 时间触发控件。
- 280px 共享面板。
- 小时/分钟步进器与快捷时间。
- 24 小时制、5 分钟步长。
- 颜色、圆角和阴影。
- 键盘、ARIA、离线与无动效规则。

新页面验收清单增加时间选择器检查项。

## 13. 验收标准

1. 原型中不再存在 `input[type="time"]`。
2. 开始时间和结束时间均为 Good Solid 触发按钮。
3. 两个字段共用一个时间面板。
4. 面板为 280px 白底、15.2px 圆角和 Good Dropdown 阴影。
5. 小时范围、分钟范围和 5 分钟步长正确。
6. 小时和分钟循环规则正确。
7. 六个快捷时间可直接选择。
8. “清除”和固定“现在 09:40”可用。
9. 点击外部、Esc 和父弹窗关闭均能关闭面板。
10. 日期面板与时间面板互斥。
11. 焦点正确进入和归还。
12. Spinbutton ARIA 值与显示值一致。
13. ArrowUp/Down、PageUp/PageDown、Home、End 和 Enter 可操作。
14. 开始时间初始 `14:00`，结束时间初始 `15:00`。
15. 不引入外部依赖和动效。
16. 1366×768 到任意更大视口无页面级溢出。
17. 现有日期选择器、五类弹窗和所有回归测试继续通过。
