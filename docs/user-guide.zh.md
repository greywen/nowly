# Nowly 用户指南

[English](user-guide.en.md) · [产品介绍](../README.zh.md) · [隐私与数据](privacy-and-data.zh.md)

## 从自己的这一天开始

把 Nowly 当作个人 Windows 工作桌面：先放日程、用四象限或看板整理任务、随手记便签，再按需要添加时间或贴纸。在 **编辑布局 → 添加模块** 中选择模块，在 12×8 网格内拖动和缩放；没有空位时先缩小或移除其它模块。空布局显示欢迎画布；回退布局含日历、四象限和便签，看板、时间和贴纸按需添加。

普通窗口、壁纸、托盘、快捷面板和全屏专注分别服务于不同场景。AI 与连接外部日历均为可选；本地任务、便签与专注不要求连接它们。Nowly 不是团队协作工作区。

> 当前版本暂时隐藏 AI 聊天入口、Nowly Bar 中的 AI 助手配置和「模型设置」页；已有 AI 数据与配置保留，其他功能不受影响。

## 功能特性

- **月历** —— 创建带时间、颜色的日程，支持按天查看详情，让今天的安排始终在视野里。
- **艾森豪威尔矩阵** —— 按「紧急 / 重要」四象限整理任务，让「马上做」象限保持诚实。
- **时间与独立闹钟** —— 从模块选择器添加「时间」，统一显示世界时钟或专注时段。模块标题保留「时间」；标题栏右侧用时钟 / 计时器图标切换显示内容。设置中的「世界时钟 / 专注时段 / 闹钟」Tab 只改配置，不切换模块显示。
  所有城市共用显示模式、横排/上下排布局、小时制、自动/手动字号及显示秒、城市、日期、时差的全局设置；每个城市仅配置名称、时区和排序。手动字号使用 32–160px 滑块，日期使用独立开关。修改立即反馈并自动保存；失败保留修改并提供重试，关闭设置不撤销修改。「时差对照」工具已移除，可选时差文字仍保留。
  专注设置仅包含 1–720 分钟的默认时长，不显示记录或统计；只有模块显示专注时段时，标题栏显示「专注统计」。切换显示不打断正在进行的计时，显示时间时用状态条提示后台专注。
  从设置「闹钟」页新建闹钟，需确认创建一次；已有闹钟在对应列表项内展开编辑，有效修改自动保存，结束编辑不撤销修改，删除仍需确认。闹钟 Tab 不显示数量。闹钟不能选择日期：关闭重复后在下一个指定本地时刻响一次，开启重复后选择星期；新建默认为 09:00、周一至周五。
  闹钟与日历共用时间选择器，可直接输入 00–59 的任意分钟；输入、快捷时间与「现在」只修改草稿，「确定」或 Enter 提交，Esc 或点击外部取消未确认修改。无效时间或空重复星期不保存。
  升级到无日期闹钟格式时，仅一次性清空旧闹钟、相关响铃/错过提醒和闹钟调度状态；日历、任务、专注记录、世界时钟及其他设置保留。
  闹钟统一按电脑本地时间触发，由 Nowly Bar 提供确认和稍后 5 分钟。启用的闹钟音效每次最多播放 1 分钟，超时停止声音，Nowly Bar 保留待处理提醒；点击关闭或确认结束本次提醒，稍后提醒则延迟 5 分钟再次响铃。需保持 Nowly 在后台或托盘运行；重启或休眠恢复后只汇总一次错过提醒，不逐条补弹。移除时间模块不会禁用闹钟，完全退出不会留下 Windows 系统调度任务。
- **专注计时器** —— 倒计时专注会话，支持无干扰全屏模式与会话统计。桌面版由原生全局计时器统一管理，主页面、全屏专注和 Nowly Bar 显示同一份剩余时间；窗口恢复可见时重新同步。
- **看板** —— 可自定义泳道、卡片和字段，进行轻量级项目跟踪。
- **便签** —— 快速记录，并提供独立的管理器整理条目。
- **贴纸** —— 可选的图片与纯文字画布，支持原图、圆角、圆形、相纸样式，以及文字字号、颜色、粗体/斜体/下划线、对齐和换行。对象可移动、缩放、旋转、调整透明度、管理图层、锁定、复制与删除。
- **壁纸模式** —— 将 Nowly 嵌入桌面图标之后，支持任务栏感知定位，也可作为
  普通窗口运行。
- **灵活布局** —— 在 12×8 网格上自由摆放每个模块，可开关模块并自由调整大小。
- **个性化** —— 高斯模糊、全局取色器、日历格式、密度控制以及开机自启。
- **提醒音效** —— 八段内置音效，分别用于日历、闹钟、错过闹钟汇总和专注完成。在 **设置 → 声音** 选择并试听各场景音效。声音始终启用，音量由系统音量或系统音量混合器控制，不提供应用内静音或音量设置；旧静音场景恢复默认音效，其他已选音效保留。音效选择保存后生效，桌面版在后台运行时也能播放，系统通知不重复播放系统提示音。
- **截图与截图历史** —— Nowly Bar 一键截图、可配置全局快捷键、统一 PNG 归档及 Bar 内展开的历史面板。
- **多语言** —— 支持英文与简体中文，启动时跟随系统语言；切换语言会同步到截图与 Nowly Bar 窗口。缺失翻译回退英文，无法国际化的原生界面（如日历授权回调页）默认使用英文。

## 使用说明

- 点击右上角按钮，将 Nowly 设为壁纸。
- 双击壁纸或点击托盘图标，返回前台窗口模式；同一进程中恢复进入壁纸前的窗口大小、位置及最大化状态。
- 打开 **设置**，可控制壁纸关闭行为、开机自启、日历格式、密度以及模块可见性。
- 关闭开机自启并保存会移除当前用户的启动项；启动项已被系统或手动移除时也可正常保存。
- 当启用壁纸偏好时，关闭前台窗口会恢复壁纸；否则窗口会隐藏到托盘。
- 托盘菜单中的 **退出 Nowly** 是唯一会终止进程的操作。

### 贴纸画布

在「编辑布局 → 添加模块」中添加「贴纸」；网格已满时先移除或缩小其他模块。
前台点击画布空白位置显示「添加文字 / 上传图片」，在点击位置添加对象，无需弹窗。文字单击直接编辑，文本框随内容、字号和样式适配；选中对象后显示单行浮动工具条，超出模块宽度可横向滚动。文字样式、字号、透明度和图层通过下拉框选择，颜色点击当前色块展开，锁定使用图标；不再显示「更多」或几何数值字段。图片支持选择文件、拖放、粘贴及替换：
仅支持 PNG、JPEG、静态 WebP，单图最大 10 MiB，宽高不超过 4096 且不超过 1600 万像素；
保留透明通道，不自动抠图。圆形样式会裁切图片，其他样式完整显示且不改变原文件。

每块画布最多 50 个对象；文字最多 2000 个 Unicode 字符，字号为 12–160px。
800×600 透明画布随模块等比适配，窗口或模块尺寸变化不会打乱排版。
从图层列表可以选择被遮挡、透明或锁定的对象；解锁后再修改。拖动文字框边缘移动，顶部手柄旋转，角落手柄调整文字字号或等比缩放图片。聚焦对象后方向键移动，Shift 加速，Alt + 左右旋转，Alt + 上下缩放。图层「默认」恢复当前会话的初始相对层序，重载后以保存顺序为基准。过长文字、越界几何或非法输入会明确提示，不允许保存裁切后的文字。

修改停止约 500 ms 后自动保存，拖动结束立即保存。失败保留草稿并提供重试；版本冲突不会覆盖已有作品。图片在成功保存后清理，清理失败可单独重试。壁纸及布局编辑模式只读。
移除模块只隐藏作品，重新添加会恢复。图片和排版保存在本地，现有便签/任务附件的
1 MiB 限制不受影响。浏览器开发模式使用 IndexedDB，刷新后也保留作品。
第一版不提供在线素材库、动画贴纸、字体导入、抠图或文件导出。

### Nowly Bar 显示模式

在 **设置 → 通知** 将 Nowly Bar 设为 **仅通知** 时，没有待处理通知的 Bar 会收成顶边细条，而不是完全隐藏。鼠标移入细条后，同一外壳向下舒展为完整 Bar；移出后向上收回。悬停只显示 Bar，点击状态区或 Logo 才打开对应面板。

待处理通知、已打开的提醒详情/菜单/AI/历史面板、Bar 内键盘焦点和进行中的操作会保留完整表面，避免丢失提醒或打断输入。面板关闭后再按当前状态决定是否收回；Tab 可以进入细条，系统开启“减少动态效果”时即时切换。常驻模式不变；禁用 Bar 或截图抑制期间连细条也隐藏，透明区域不拦截桌面点击。

### 截图与截图历史

点击 **Nowly Bar 的 Logo** 展开功能菜单，选择 **截图、截图历史或 AI 助手**。在 **设置 → 通知 → Nowly Bar → 功能菜单** 中设置显示/隐藏和顺序；新安装及旧版升级默认显示三项。隐藏只影响菜单，不影响快捷键；允许全部隐藏，菜单会显示重新启用的设置说明。截图默认快捷键 **Ctrl+Alt+A**，截图历史默认 **Ctrl+Alt+H**；在 **设置 → 快捷键** 中修改。快捷键冲突会明确提示，不会阻止应用启动。

“保存”直接写入系统 **图片\Nowly\Screenshots**，不再弹出另存为。“复制图片并完成”也先保存最终 PNG，再写入图片剪贴板。只保存裁切、标注和马赛克后的最终结果；取消不产生记录。系统图片目录被重定向时，保存位置随系统设置变化。

截图历史直接从屏幕顶边的 Nowly Bar 动画展开，不再打开独立窗口。折叠 Bar 固定 **288 × 40px**，仅保留提醒/状态区和 Logo 入口；提醒、功能菜单、AI 和历史面板的展开宽度统一为 **432px**。使用历史快捷键前需启用 Nowly Bar。按 Esc、点击关闭键或面板外部即可收起；删除确认打开时 Esc 优先取消确认，再点 Logo 回到功能菜单。面板提供缩略图、复制图片、确认删除和打开文件夹。记录一直保留；确认删除同时删除本地 PNG 和缩略图缓存。不要将此目录当作自动清理的临时文件夹。

归档失败时保留截图编辑内容，不执行复制；图片已保存但剪贴板写入失败时可重试，同一最终图片不会重复归档。历史复制不增加新记录。缩略图缓存可重建，原图不会存入 SQLite；原始整屏底图只用于当前截图会话。

#### 图片钉住

在截图工具栏点击 **钉住**，将当前裁切和标注后的最终图片显示为独立桌面置顶窗口，可跨应用查看、拖动和关闭。图片按窗口内容区等比完整显示，不提供放大、缩小按钮。普通截图和确认后的长截图均可钉住。最多同时 **5 张**；第 6 张会提示先关闭一张，当前编辑内容仍保留。钉图不自动复制到剪贴板，也不替代保存；需要长期保留时请使用保存。

开始下一次截图时，已有钉图暂时隐藏，结束或取消后恢复，不抢焦点。关闭一张即可释放名额；退出程序后不恢复钉图。

#### 手动滚动长截图

1. 在同一屏幕内框选需要向下滚动的内容，避开固定侧栏、视频和无关窗口；在添加标注前点击 **滚动截图**。
2. 点击 **开始采集**，等待首帧就绪后，在原窗口内手动缓慢向下滚动，每次保留重叠并稍作停顿。程序只负责采集和自动拼接，不发送滚轮输入，控制区显示已确认的长图预览及高度；可暂停、继续、停止或取消。
3. 点击 **完成并审核** 或按 **Esc** 查看结果，检查接缝和内容，选择 **使用长图** 后继续标注、复制、保存或钉住。异常停止时选择 **使用已截部分**；取消长截图则返回原普通截图。

滚动采集期间，可能遮挡目标的 Nowly 主窗口会暂时隐藏，结束或取消后恢复先前的可见状态，不改变置顶偏好。切换应用、目标移动或缩放、遮挡、内容无法可靠拼接时会停止采集并保留已确认部分。静止或滚到底时保持等待，不自动结束，请点击完成。取消不会将原应用滚回原位置。暂不支持跨屏、横向或自动滚动模式，不会自动提升权限操作受保护应用。输出最多 **6400 万像素**，任一边不超过 **65535 像素**；达到限制后只能使用已截部分或取消。

浏览器开发模式仅用于验证界面，不能操作真实截图文件、桌面滚动采集或系统全局快捷键；完整功能需在 Windows 桌面应用中运行。

## 连接外部日历

打开日历模块设置中的订阅管理。本地事件无需连接账户。添加 feed 时选择 ICS，填写名称与 HTTPS/webcal 地址，设置分类和刷新间隔；连接 Google/Microsoft 时在供应商浏览器授权流程登录，再勾选日历并订阅。最多 50 个来源，间隔 1–30 分钟，默认 15 分钟。可手动刷新重试；失败保留上次成功事件，使用前注意同步状态和缓存时效。

ICS 事件只读。授权可写的 Google/Microsoft 来源可以作为新建日程的目标，普通事件编辑器可远程修改和删除；这会向供应商发送事件内容，不是仅在本地保存。不支持创建/修改远程重复规则。断开连接删除本地账户及关联订阅/缓存，不撤销供应商端授权，也不删除远端日历；需要时另到供应商设置撤销访问。详见 [隐私与数据](privacy-and-data.zh.md)。

## 按需使用 AI 助手

打开 AI 设置，填写完整 API 地址、Model ID 和 Key，选择允许读取的本地日历、任务及/或外部日历。保存/连接发送固定 JSON 测试并检测协议。远程服务要求 HTTPS 与 Key，本机 loopback 可用 HTTP，也可无需 Key；更换地址不会自动沿用旧 Key。连接失败保留之前已保存的设置。

从主工作区或 **Nowly Bar Logo → AI 助手** 打开面板，例如询问「查看未完成的重要任务」或「明天 19:00 创建学习日程」。仔细查看绝对日期、对象与变更内容；不明确的信息先澄清，需要修改时选择/编辑预览并重新生成。只有明确的确认按钮执行本地方案，取消或停止不代表确认。

每份方案为同一领域的 1–20 个唯一动作，五分钟后过期，重启应用后不能确认旧预览。AI 支持本地日程/任务的创建、修改与删除，不支持任意代码或看板管理；已有重复日程只能对已查询的明确某一次修改/删除，不支持重复规则或单次实例提醒偏移修改。日程加任务请求需拆开。日历查询最多 90 天、每次最多 200 条，结果不完整时先缩小范围再批量修改。数据或权限改变后可能需要重新查询/预览。本地操作方案历史为最近七天；撤销会检查相关数据，发生变化时可能拒绝，并非还原整个数据库。

允许的查询结果、用户输入、近期对话及上一份草稿会发送给配置的模型接口。外部开关包含 Google、Microsoft 和 ICS 缓存事件；即使普通编辑器可写，AI 对它们仍只读。权限开关不脱敏既有对话文字。可用时语音只填写草稿、不自动发送，其宿主识别服务不能保证离线。连接前请阅读 [准确 AI 上下文边界](privacy-and-data.zh.md#可选-ai准确的上下文边界)。

## 桌面模式与数据维护

快捷面板是独立的屏幕顶边原生界面，不等同于把工作区嵌入壁纸；全屏专注是独立专注视图，不是壁纸模式，切换视图时共用计时状态。「设置 → 界面 → 壁纸模式外观」提供两个独立选项：「隐藏导航栏及模块顶部栏」默认勾选；「隐藏模块背景颜色和边框」默认不勾选，仅隐藏模块外壳，保留内部卡片、任务行和输入框样式。两项都只在壁纸模式生效，返回普通窗口恢复原样，不改变布局、模块正文或独立 Nowly Bar。

壁纸/托盘运行不是备份。SQLite 只覆盖桌面数据的一部分，附件、贴纸文件、截图与相关 WebView 存储也应保留。换电脑或手动重置开发数据前，先阅读 [备份与控制](privacy-and-data.zh.md#备份与控制)。

## 技术栈

- **前端** —— React + TypeScript，基于 Vite 构建，样式为手写 CSS，全部取值来自 `design.md`
  的 Token，不使用工具类或 CSS-in-JS 框架。
- **桌面外壳** —— Tauri 2，后端使用 Rust。
- **存储** —— 桌面结构化记录使用 SQLite；附件、贴纸图片和截图使用独立文件，部分界面偏好使用 WebView 本地存储。
- **图标** —— Solar 字形通过 `src/components/icons.tsx` 统一引入，用 `npm run icons` 重新生成；双色、实心、线性风格可在设置中切换。
- **测试** —— Vitest 负责单元/组件测试，Playwright 负责端到端测试，
  `cargo test` 负责 Rust 层测试。

## 开发

环境要求：Node.js、Rust 工具链，以及 Windows 下的 Tauri 依赖。

```powershell
npm install                                        # 安装依赖
npm run dev                                         # Vite 开发服务器（127.0.0.1:1420）
npm test                                            # Vitest 单元/组件测试
npm run build                                       # tsc + vite build
npx playwright test                                 # 端到端测试
cargo test --manifest-path src-tauri\Cargo.toml     # Rust 测试
npm run tauri build                                 # 构建 Windows 可执行文件
```

统一时间/专注设置是开发阶段的不兼容改动，不迁移旧的逐时钟设置。重置前应先备份开发数据库；
仅 Debug 构建可通过 `NOWLY_RESET_DEVELOPMENT_TIME_V32` 指定数据库的准确绝对路径，
执行一次性限定重置：时间/专注设置、闹钟及相关通知、专注记录和旧模块条目。其它数据保留，
Release 构建不会执行此重置。浏览器开发后端独立重置本地存储中的旧时间/专注数据。

## 项目结构

```text
src/                 React 前端
  app/               应用外壳、布局网格、启动钩子
  calendar/          月历与日程
  matrix/            艾森豪威尔任务矩阵
  kanban/            看板
  notes/             便签
  focus/             专注计时器与统计
  time/              统一时间/专注模块、世界时钟与闹钟设置
  widgets/           模块注册表、选择器与网格布局
  components/        共享 UI（Dialog、Select、DatePicker 等）
  data/              仓储接口与 Tauri 实现
  i18n/              多语言（en/zh）
src-tauri/           Rust 后端（Tauri 命令、SQLite、壁纸、托盘）
docs/                设计规格与实施计划
```
