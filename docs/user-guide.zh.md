# Nowly 用户指南

[English](user-guide.en.md) · [产品介绍](../README.zh.md) · [隐私与数据](privacy-and-data.zh.md)

## 从自己的这一天开始

把 Nowly 当作个人 Windows 工作桌面：先放日程、用四象限或看板整理任务、随手记便签，再按需要添加时间或贴纸。在 **编辑布局 → 添加模块** 中选择模块，在 12×8 网格内拖动和缩放；没有空位时先缩小或移除其它模块。空布局显示欢迎画布；回退布局含日历、四象限和便签，看板、时间和贴纸按需添加。

普通窗口、壁纸、托盘、快捷面板和全屏专注分别服务于不同场景。AI 与连接外部日历均为可选；本地任务、便签与专注不要求连接它们。Nowly 不是团队协作工作区。

> 当前版本暂时隐藏 AI 聊天入口、Nowly Bar 中的 AI 助手配置和「AI 助手」设置页；已有 AI 数据与配置保留，其他功能不受影响。

## 功能特性

- **月历** —— 创建带时间、颜色的日程，支持按天查看详情，让今天的安排始终在视野里。在日程表单的「分类」中可直接新增分类；创建后自动选中并使用其颜色，无需关闭或重新打开表单即可保存日程。新建日程默认提前 15 分钟提醒，已有日程的提醒保持不变，也可取消提醒。时间面板不再显示「清除 / 现在 / 确定」：快捷时间直接选定并收起；增减和方向键即时生效，直接输入在失焦或 Enter 时提交，Enter 同时收起。点击外部提交有效输入，Esc 仅放弃尚未提交的输入，已生效的选择不回滚。起止时间共享本机保存的最近 6 个不同时间，最近使用优先；不足 6 个时以常用时间补齐，不记录自动推算的结束时间。
- **艾森豪威尔矩阵** —— 按「紧急 / 重要」四象限整理任务，让「马上做」象限保持诚实。
- **时间与独立闹钟** —— 从模块选择器添加「时间」，统一显示世界时钟或专注时段。模块标题保留「时间」；标题栏右侧用时钟 / 计时器图标切换显示内容。设置中的「世界时钟 / 专注时段 / 闹钟」Tab 只改配置，不切换模块显示。
  所有城市共用显示模式、横排/上下排布局、小时制、自动/手动字号及显示秒、城市、日期、时差的全局设置；每个城市仅配置名称、时区和排序。手动字号使用 32–160px 滑块，日期使用独立开关。12 小时制统一补足两位（如 02:02、02:10、11:02），上午/下午或 AM/PM 等时段文字按语言显示在时间右下角，字号固定为小字；24 小时制不显示时段文字。修改立即反馈并自动保存；失败保留修改并提供重试，关闭设置不撤销修改。「时差对照」工具已移除，可选时差文字仍保留。
  专注设置仅包含 1–720 分钟的默认时长，不显示记录或统计；只有模块显示专注时段时，标题栏显示「专注统计」。切换显示不打断正在进行的计时，显示时间时用状态条提示后台专注。
  点击时间模块标题栏的添加图标，直接进入设置「闹钟」页并展开新建表单，也可从该页新建闹钟，需确认创建一次；已有闹钟在对应列表项内展开编辑，有效修改自动保存，结束编辑不撤销修改，删除仍需确认。闹钟 Tab 不显示数量。闹钟不能选择日期：关闭重复后在下一个指定本地时刻响一次，开启重复后选择星期；新建默认使用打开表单时的电脑本地时间、周一至周五。
  闹钟时间选择器可直接输入 00–59 的任意分钟；闹钟仍保留确认模式，输入、固定快捷时间与「现在」只修改草稿，「确定」或 Enter 提交，Esc 或点击外部取消未确认修改。无效时间或空重复星期不保存。
  升级到无日期闹钟格式时，仅一次性清空旧闹钟、相关响铃/错过提醒和闹钟调度状态；日历、任务、专注记录、世界时钟及其他设置保留。
  闹钟统一按电脑本地时间触发，由 Nowly Bar 提供确认和稍后 5 分钟。启用的闹钟音效每次最多播放 1 分钟，超时停止声音，Nowly Bar 保留待处理提醒；点击关闭或确认结束本次提醒，稍后提醒则延迟 5 分钟再次响铃。需保持 Nowly 在后台或托盘运行；重启或休眠恢复后只汇总一次错过提醒，不逐条补弹。移除时间模块不会禁用闹钟，完全退出不会留下 Windows 系统调度任务。
- **专注计时器** —— 倒计时专注会话，支持无干扰全屏模式与会话统计。桌面版由原生全局计时器统一管理，主页面、全屏专注和 Nowly Bar 显示同一份剩余时间；窗口恢复可见时重新同步。计时结束后，Nowly Bar 持续显示专注已完成，保存专注记录不会使提示消失；可手动关闭提示或开始下一次专注。
- **看板** —— 在看板新建的任务也会按象限出现在四象限，两处修改同步；在四象限新建的任务只留在四象限，不进入泳道。点泳道或象限末尾的「+ 添加任务」，输入标题按回车即可建好，输入框保持打开，可以连续添加；Esc 收起。在泳道里添加的任务默认放在「不重要不紧急」。看板一开始没有泳道，按需要自己建。「已完成」不是泳道：在四象限勾选任务，或把卡片拖到看板底部的「拖到这里标记完成」，任务就离开泳道。工具栏的「已完成」按钮显示最近 7 天完成的任务数，点开可以查看（「查看全部」包含更早的）；取消勾选后任务回到原泳道顶部。四象限中未完成的任务可以直接拖进泳道。四象限中在看板上的未完成任务会显示所在泳道。卡片只显示象限色点、标题，以及截止日期、步骤、附件和标签（有值时）。泳道名称右侧的「⋯」菜单可以重命名与改色、在右侧新建泳道或删除泳道。最后一个泳道也可以删除；删除后其中的任务离开看板，仍保留在四象限。工具栏的「管理标签」用来增删标签，「新建任务」打开完整的任务弹框。泳道编辑、删除失败只在操作弹框内显示原因，不在看板或四象限重复提示；拖放失败仍在对应模块内提示。
- **任务步骤** —— 在看板或四象限的任务弹框中，于「描述」下方添加步骤清单：按回车或点「添加」新增，点击文字原位改名，拖动手柄（或聚焦手柄后按上下方向键）调整顺序。步骤随「保存任务」一起保存；勾完全部步骤不会自动完成任务。看板卡片和四象限任务行显示「已完成/总数」。升级后仍可撤销此前的 AI 操作；若相关任务后来新增或修改了步骤，会拒绝撤销，以免覆盖这些改动。
- **便签** —— 在加宽的创建/编辑弹框中直接书写，保留完整富文本和附件功能。模块标题自动取正文首个非空逻辑行，不单独填写或保存标题；长标题仅显示省略。底部色点、笑脸和置顶图标分别选择颜色、装饰图标与置顶状态，全部便签可在管理器整理。空白不可新建，纯图片/附件可保存，无文字时显示「无标题便笺」。升级后旧独立标题直接删除，已有正文和附件保持不变。
- **富文本图片缩放** —— 便签、任务描述和日程备注中的图片可点击选中，再拖动右下角手柄等比例调整尺寸，宽度不超过编辑区。聚焦手柄后，方向键每次调整 10px，按住 Shift 每次调整 1px；Esc 取消当前拖动。尺寸支持撤销/重做，并随正文保存，重新打开后恢复，不修改原始附件。
- **贴纸** —— 可选的图片与纯文字画布，支持原图、圆角、圆形、相纸样式，以及文字字号、颜色、粗体/斜体/下划线、对齐和换行。对象可移动、缩放、旋转、调整透明度、管理图层、锁定、复制与删除。
- **壁纸模式** —— 将 Nowly 嵌入桌面图标之后，支持任务栏感知定位，也可作为
  普通窗口运行。
- **灵活布局** —— 在 12×8 网格上自由摆放每个模块，可开关模块并自由调整大小。
- **个性化** —— 高斯模糊、全局取色器、日历格式、密度控制以及开机自启。
- **提醒音效** —— 八段内置音效，分别用于日历、闹钟、错过闹钟汇总和专注完成。在 **设置 → 声音** 选择并试听各场景音效。声音始终启用，音量由系统音量或系统音量混合器控制，不提供应用内静音或音量设置；旧静音场景恢复默认音效，其他已选音效保留。音效选择保存后生效，桌面版在后台运行时也能播放。日程、专注结束和闹钟统一通过 Nowly Bar 提醒，不再发送 Windows 系统通知；声音不依赖 Windows 通知权限。
- **截图与截图历史** —— Nowly Bar 一键截图、可配置全局快捷键、统一 PNG 归档及 Bar 内展开的历史面板。
- **快速创建** —— 不打开主窗口，从 Nowly Bar 功能菜单或可选的全局快捷键直接新建日程、四象限任务和便签。
- **多语言** —— 支持简体中文、英文、法语、西班牙语、日语、韩语和繁体中文。未手动选择语言时，启动直接读取 Windows 当前用户的界面语言（网页版读取浏览器主语言），匹配对应的应用语言；无法读取或不支持时默认英文，不改选其他备选语言。手动选择会保存并优先恢复，切换语言会同步到截图与 Nowly Bar 窗口。缺失翻译回退英文，无法国际化的原生界面（如日历授权回调页）默认使用英文。

## 使用说明

- 点击右上角按钮，将 Nowly 设为壁纸。
- 双击壁纸或点击托盘图标，返回前台窗口模式；同一进程中恢复进入壁纸前的窗口大小、位置及最大化状态。
- 打开 **设置**，可控制壁纸关闭行为、开机自启、日历格式、密度以及模块可见性。
- 关闭开机自启并保存会移除当前用户的启动项；启动项已被系统或手动移除时也可正常保存。
- 当启用壁纸偏好时，关闭前台窗口会恢复壁纸；否则窗口会隐藏到托盘。
- 托盘菜单中的 **退出 Nowly** 是唯一会终止进程的操作。

### 便签导出

在便签模块打开 **查看全部便签 → 导出便签**，勾选需要的便签（支持全选/取消全选），即可导出为 Markdown。编辑已有便签时，也可以点击弹框顶部的 **导出便签**，导出当前草稿；这不会自动保存修改。

- 没有附件的单条便签直接保存为 `.md`；批量或含本地附件时保存为一个 ZIP，每条便签有独立目录。**先完整解压 ZIP，再打开 `.md` 文件**，并保留同目录的 `assets/` 文件夹，否则本地图片无法显示。
- Markdown 保留标题、列表、待办、表格、代码和链接，颜色、字号和对齐会简化；公式保留 TeX 源码。
- 外部图片和视频只导出链接，不自动联网下载。本地附件缺失时整次导出会失败，恢复文件后可以重试；不会修改原便签。
- 导出上限为 256 MB；超限时减少所选便签。取消系统“另存为”不会写出文件。浏览器开发模式仅支持 Markdown/ZIP 下载。

### 贴纸画布

在「编辑布局 → 添加模块」中添加「贴纸」；网格已满时先移除或缩小其他模块。
前台点击画布空白位置显示「添加文字 / 上传图片」，在点击位置添加对象，无需弹窗。文字单击直接编辑，文本框随内容、字号和样式适配；选中对象后显示单行浮动工具条，超出模块宽度可横向滚动。文字样式、字号、透明度和图层通过下拉框选择，颜色点击当前色块展开，锁定使用图标；不再显示「更多」或几何数值字段。图片支持选择文件、拖放、粘贴及替换：
仅支持 PNG、JPEG、静态 WebP，单图最大 10 MiB，宽高不超过 4096 且不超过 1600 万像素；
保留透明通道，不自动抠图。圆形样式会裁切图片，其他样式完整显示且不改变原文件。

每块画布最多 50 个对象；文字最多 2000 个 Unicode 字符，字号为 12–160px。
800×600 透明画布随模块等比适配，窗口或模块尺寸变化不会打乱排版。
从图层列表可以选择被遮挡、透明或锁定的对象；解锁后再修改。拖动文字框边缘移动，顶部手柄旋转，角落手柄调整文字字号或等比缩放图片。聚焦对象后方向键移动，Shift 加速，Alt + 左右旋转，Alt + 上下缩放。图层「默认」恢复当前会话的初始相对层序，重载后以保存顺序为基准。过长文字、越界几何或非法输入会明确提示，不允许保存裁切后的文字。

修改停止约 500 ms 后自动保存，拖动结束立即保存。失败保留草稿并提供重试；版本冲突不会覆盖已有作品。图片在成功保存后清理，清理失败可单独重试。壁纸及布局编辑模式只读。
移除模块只隐藏作品，重新添加会恢复。图片和排版保存在本地，现有便签/任务附件的
1 MiB 限制不受影响。浏览器开发模式使用 IndexedDB，刷新后也保留作品。
第一版不提供在线素材库、动画贴纸、字体导入、抠图或文件导出。

### Nowly Bar 显示模式

日程提醒、专注结束和闹钟均在 Nowly Bar 显示，不写入 Windows 通知中心，也不提供锁屏系统通知。请保持 Nowly 运行；主窗口最小化或隐藏到托盘后仍可提醒，完全退出后不再提醒。保存失败、表单校验和截图结果等操作反馈仍显示在相关操作位置。

在 **设置 → 通知** 将 Nowly Bar 设为 **仅通知** 时，没有待处理通知的 Bar 会收成顶边细条，而不是完全隐藏。鼠标移入细条后，同一外壳向下舒展为完整 Bar；移出后向上收回。悬停只显示 Bar，点击状态区或 Logo 才打开对应面板。

待处理通知、已打开的提醒详情/菜单/AI/历史面板、Bar 内键盘焦点和进行中的操作会保留完整表面，避免丢失提醒或打断输入。面板关闭后再按当前状态决定是否收回；Tab 可以进入细条，系统开启“减少动态效果”时即时切换。常驻模式不变；截图抑制期间连细条也隐藏，透明区域不拦截桌面点击。

### Nowly Bar 功能菜单

点击 **Nowly Bar 的 Logo** 展开功能菜单。菜单分为两组：**快速创建**（日程、四象限任务、便签）和 **截图**（截图、截图历史）。每项只显示图标和名称，整体水平、垂直居中，不显示快捷键。名称过长时最多显示两行，超出部分以省略号结尾；方向键按显示顺序移动焦点，Home / End 跳到首项和末项。

在 **设置 → 通知 → Nowly Bar → 功能菜单** 中按组设置各项的显示/隐藏和组内顺序，组的先后顺序固定。新安装及旧版升级默认显示全部项。组内全部隐藏时不显示该组；允许全部隐藏，菜单会显示重新启用的设置说明。隐藏只影响菜单，不影响快捷键。

### 快速创建

在功能菜单的 **快速创建** 组点击日程、四象限任务或便签，菜单收起，在 Bar 正下方弹出对应的新建弹框，不需要打开主窗口。弹框与应用内的新建弹框字段相同；新建任务默认放入「不重要不紧急」，不进入看板泳道。

- 保存成功后弹框关闭，主窗口中对应的日历、四象限或便签随即刷新；保存失败时弹框保持打开并显示错误。
- 取消、关闭键、Esc 或 Alt+F4 关闭弹框，有未保存的改动时先确认放弃。点击弹框外部或切换到其他应用不会关闭弹框。
- 弹框打开时再次选择同一类型，会回到已打开的弹框并保留草稿。选择其他类型时，未改动直接切换；有改动先确认放弃，取消则保留原草稿。
- 弹框高度不超过屏幕工作区，内容较多时只滚动弹框正文。
- 截图期间弹框暂时隐藏，截图结束后恢复。

在 **设置 → 快捷键 → 快速创建** 中可为「新建日程」「新建四象限任务」「新建便签」录制全局快捷键，默认均为 **未设置**。设置后在任何应用中按下即可直接打开对应弹框；点击清除按钮恢复为未设置。所有全局快捷键（包括截图和截图历史）不能重复。

### 语音输入

按住说话键说出要做的事，松开后 Nowly 在本机识别语音，再交给配置好的模型创建日程、四象限任务或便签，例如「今天下午三点安排一个项目讨论会议」或「帮我记录下：周五前交报告」。

- 先在 **设置 → AI 助手** 中填写 API 地址和 Key，从自动获取的列表中选择模型（也可直接输入名称），并允许对应的数据范围，再在同页的 **语音输入** 分组中启用「按住说话」并下载本地识别模型（约 240 MB）。默认关闭。
- 默认按住 **Ctrl+Win**，可改为两个以上修饰键、修饰键加一个键或单个 F 键；还可选择麦克风和识别语言（自动 / 中文 / 英文）。
- 按住时 Nowly Bar 的 Logo 变为麦克风并展开为聆听态，显示实时文字、电平和计时；松开后显示「正在理解」，可点停止取消。
- 新建结果直接显示在 Bar 上，15 秒内可点「撤销」；修改、删除和外部日历写入在 Bar 上显示「N 秒后执行」，15 秒内不取消就会执行，鼠标悬停或聚焦卡片时暂停倒计时。模型需要补充信息时，再次按住说话键回答。
- 缺少模型、麦克风不可用或模型未配置时，Bar 显示原因及去设置或打开系统麦克风设置的按钮。
- 以管理员身份运行的窗口在前台时，系统不允许 Nowly 接收按键，按住说话不起作用。

### 截图与截图历史

在功能菜单的 **截图** 组选择截图或截图历史。截图默认快捷键 **Ctrl+Alt+A**，截图历史默认 **Ctrl+Alt+H**。**设置 → 快捷键** 中的五项快捷键使用统一操作：点击输入框后按组合键录制，点击右侧 **×** 清除按钮，或在输入框中按 Backspace / Delete，恢复为 **未设置**。点击 **保存设置** 后生效；清除会解除对应全局快捷键，重新打开设置或重启不会恢复默认值，功能菜单入口仍可使用。已设置的快捷键不能重复；冲突会明确提示，不会阻止应用启动。

“保存”直接写入系统 **图片\Nowly\Screenshots**，不再弹出另存为。“复制图片并完成”也先保存最终 PNG，再写入图片剪贴板。只保存裁切、标注和马赛克后的最终结果；取消不产生记录。系统图片目录被重定向时，保存位置随系统设置变化。

截图历史直接从屏幕顶边的 Nowly Bar 动画展开，不再打开独立窗口。折叠 Bar 固定 **288 × 40px**，仅保留提醒/状态区和 Logo 入口；提醒、功能菜单、AI 和历史面板的展开宽度统一为 **432px**。按 Esc、点击关闭键或面板外部即可收起；删除确认打开时 Esc 优先取消确认，再点 Logo 回到功能菜单。面板提供缩略图、复制图片、确认删除和打开文件夹。记录一直保留；确认删除同时删除本地 PNG 和缩略图缓存。不要将此目录当作自动清理的临时文件夹。

归档失败时保留截图编辑内容，不执行复制；图片已保存但剪贴板写入失败时可重试，同一最终图片不会重复归档。历史复制不增加新记录。缩略图缓存可重建，原图不会存入 SQLite；原始整屏底图只用于当前截图会话。

#### 图片钉住

在截图工具栏点击 **钉住**，将当前裁切和标注后的最终图片显示为独立桌面置顶窗口，可跨应用查看和关闭。按住顶部导航栏空白处拖动窗口；按住图片或图片周围留白不会移动窗口。拖拽窗口边缘或四角可等比例放大、缩小窗口（最小 240 × 96px）：图片内容区宽高比保持不变，另一边同步变化，工具栏高度不变。图片随内容区等比完整显示，不提供单独的放大、缩小按钮。普通截图和确认后的长截图均可钉住。最多同时 **5 张**；第 6 张会提示先关闭一张，当前编辑内容仍保留。钉图不自动复制到剪贴板，也不替代保存；需要长期保留时请使用保存。

开始下一次截图时，已有钉图暂时隐藏，结束或取消后恢复，不抢焦点。关闭一张即可释放名额；退出程序后不恢复钉图。

#### 手动滚动长截图（暂时隐藏）

滚动截图因已知问题暂时隐藏入口，普通截图、标注、钉图、保存和复制不受影响。以下说明供功能恢复后参考。

1. 在同一屏幕内框选需要上下滚动的内容，避开固定页头/页尾、侧栏和视频；在添加标注前点击工具栏中的 **滚动截图**。
2. 点击后立即开始，全程在同一个截图界面内完成：选区外变暗但显示实时画面，选区上方提示「滚动页面截取更多内容」，旁边显示实时长图预览。直接把鼠标放在选区内用滚轮滚动页面，程序自动拼接新内容；不滚动就不追加。程序不会替你滚动。
3. 点击 **完成**（或按 Enter / Ctrl+C）复制长图并关闭截图；点击 **保存**（或 Ctrl+S）保存长图并关闭截图；点击 **取消** 或按 **Esc** 关闭整个截图。

页面滚动时连续采集，无需在每次滚动后停顿。向下越过已截末尾追加新内容，向上越过起始位置补到长图顶部；回看已截内容不删除、不重复。预览跟随最新增长的一端。无法确认像素衔接时不会猜测或覆盖已截内容，提示说明采集或匹配原因，而不要求用户控制滚速。选区包含不滚动的固定栏时会提示只框选滚动内容，本轮不自动去除固定栏。暂不支持跨屏、横向或自动滚动模式；Windows 帧驱动后端暂不支持旋转显示器。输出最多 **6400 万像素**，任一边不超过 **65535 像素**；达到上限后可直接完成，保留已截部分。

浏览器开发模式仅用于验证界面，不能操作真实截图文件、桌面滚动采集或系统全局快捷键；完整功能需在 Windows 桌面应用中运行。

## 连接外部日历

打开日历模块设置中的订阅管理。本地事件无需连接账户。添加 feed 时选择 ICS，填写名称与 HTTPS/webcal 地址，设置分类和刷新间隔；连接 Google/Microsoft 时在供应商浏览器授权流程登录，再勾选日历并订阅。最多 50 个来源，间隔 1–30 分钟，默认 15 分钟。可手动刷新重试；失败保留上次成功事件，使用前注意同步状态和缓存时效。

ICS 事件只读。授权可写的 Google/Microsoft 来源可以作为新建日程的目标，普通事件编辑器可远程修改和删除；这会向供应商发送事件内容，不是仅在本地保存。写入远端日历时，备注会转换为纯文本，不会发送内部富文本 JSON 或图片/视频嵌入；Outlook 定时事件保留设备本地时区，Google 使用等价的 UTC 时刻。不支持创建/修改远程重复规则。断开连接删除本地账户及关联订阅/缓存，不撤销供应商端授权，也不删除远端日历；需要时另到供应商设置撤销访问。详见 [隐私与数据](privacy-and-data.zh.md)。

## 按需使用 AI 助手

打开 AI 设置，填写完整 API 地址、Model ID 和 Key，选择允许读取的本地日历、任务及/或外部日历。保存/连接发送固定 JSON 测试并检测协议。远程服务要求 HTTPS 与 Key，本机 loopback 可用 HTTP，也可无需 Key；更换地址不会自动沿用旧 Key。连接失败保留之前已保存的设置。

从主工作区或 **Nowly Bar Logo → AI 助手** 打开面板，例如询问「查看未完成的重要任务」或「明天 19:00 创建学习日程」。仔细查看绝对日期、对象与变更内容；不明确的信息先澄清，需要修改时选择/编辑预览并重新生成。只有明确的确认按钮执行本地方案，取消或停止不代表确认。

每份方案为同一领域的 1–20 个唯一动作，五分钟后过期，重启应用后不能确认旧预览。AI 支持本地日程、任务和闹钟的创建、修改与删除，以及新建便签：新建日程可选分类和重复规则；任务可以设置标签、增删改步骤、在看板列之间移动或移出看板；便签支持标题、列表和待办格式。AI 不能新建或修改看板列、标签和分类，也不能改写已有便签。已有重复日程只能对已查询的明确某一次修改/删除，不支持修改重复规则或单次实例提醒偏移。日程加任务请求需拆开。日历查询最多 90 天、每次最多 200 条，结果不完整时先缩小范围再批量修改。数据或权限改变后可能需要重新查询/预览。本地操作方案历史为最近七天；撤销会检查相关数据，发生变化时可能拒绝，并非还原整个数据库。

允许的查询结果、用户输入、近期对话及上一份草稿会发送给配置的模型接口。外部开关包含 Google、Microsoft 和 ICS 缓存事件，默认对 AI 只读；另外开启「新建和修改外部日历日程」后，AI 可在可写的 Google/Microsoft 日历中新建单个日程或修改已查询的日程，不能删除。权限开关不脱敏既有对话文字。可用时语音只填写草稿、不自动发送，其宿主识别服务不能保证离线。连接前请阅读 [准确 AI 上下文边界](privacy-and-data.zh.md#可选-ai准确的上下文边界)。

## 让外部 AI 代理使用 Nowly

Codex、Claude Code、WorkBuddy 等本机 AI 代理可以通过 `nowly` 命令读取和修改 Nowly 数据，能做的事与 AI 助手相同。不需要在 Nowly 中配置模型，代理使用它自己的模型。

1. 打开 **设置 → SKILL 设置**，勾选「允许外部代理连接」，选择允许的数据范围并保存。默认全部关闭，与 AI 助手的权限分开设置。
2. 在「安装技能」中点击「复制 SKILL.md」，粘贴到代理的会话里，让它把内容安装为技能。之后修改权限不需要重新安装。
3. 在代理中直接说「把明天下午的评审会改到四点」之类的话。代理会先查询，再提出方案。

代理提出的每个方案都显示在 Nowly Bar 上，标出代理名称和「N 秒后执行」，15 秒内不取消就会执行；同时到达的多个方案依次显示。代理只能修改它最近 10 分钟内查询过的记录，可以撤销自己执行过的方案。Nowly 未运行时，`nowly` 命令会在后台启动它。

Microsoft Store 版安装后即可在终端使用 `nowly`；安装包版的命令是安装目录中的 `nowly-cli.exe`，`SKILL.md` 中已写好完整路径。代理读取的内容会发送给代理所用的模型服务商，详见 [外部 AI 代理](privacy-and-data.zh.md#外部-ai-代理)。

## 桌面模式与数据维护

快捷面板是独立的屏幕顶边原生界面，不等同于把工作区嵌入壁纸；全屏专注是独立专注视图，不是壁纸模式，切换视图时共用计时状态。「设置 → 界面 → 壁纸模式外观」提供两个独立选项：「隐藏导航栏及模块顶部栏」默认勾选；「隐藏模块背景颜色和边框」默认不勾选，仅隐藏模块外壳，保留内部卡片、任务行和输入框样式。两项都只在壁纸模式生效，返回普通窗口恢复原样，不改变布局、模块正文或独立 Nowly Bar。

壁纸/托盘运行不是备份。SQLite 只覆盖桌面数据的一部分，附件、贴纸文件、截图与相关 WebView 存储也应保留。换电脑或手动重置开发数据前，先阅读 [备份与控制](privacy-and-data.zh.md#备份与控制)。

## 技术栈

- **前端** —— React + TypeScript，基于 Vite 构建，样式为手写 CSS，全部取值来自 `design.md`
  的 Token，不使用工具类或 CSS-in-JS 框架。
- **桌面外壳** —— Tauri 2，后端使用 Rust。
- **存储** —— 桌面结构化记录使用 SQLite；附件、贴纸图片和截图使用独立文件，部分界面偏好使用 WebView 本地存储。
- **图标** —— Solar 字形通过 `src/components/icons.tsx` 统一引入，用 `npm run icons` 重新生成；双色、实心、线性风格可在设置中切换。
- **测试** —— Vitest 负责单元/组件测试，Playwright 负责端到端测试，
  `cargo test` 负责 Rust 层测试。

## 开发

环境要求：Node.js、Rust 工具链，以及 Windows 下的 Tauri 依赖。

```powershell
npm install                                        # 安装依赖
npm run dev                                         # Vite 开发服务器（127.0.0.1:1420）
npm test                                            # Vitest 单元/组件测试
npm run build                                       # tsc + vite build
npx playwright test                                 # 端到端测试
cargo test --manifest-path src-tauri\Cargo.toml     # Rust 测试
npm run tauri build                                 # 构建 Windows 可执行文件
```

### Windows 开发构建的链接错误

如果 `npm run tauri dev` 出现 `LNK2019` / `LNK1120`，且缺失符号主要是
`anon.*.llvm.*`，可先停止开发进程，再从仓库根目录仅清理 Nowly 包的编译缓存并重试：

```powershell
cargo clean --manifest-path src-tauri\Cargo.toml -p nowly
npm run tauri dev
```

这类错误可能来自失效的 Rust 增量编译产物；上述命令不清理依赖包缓存，也不会删除应用数据库或用户数据。
若重建后仍失败，应保留完整链接日志继续排查；其它类型的未解析符号不一定属于缓存问题。

统一时间/专注设置是开发阶段的不兼容改动，不迁移旧的逐时钟设置。重置前应先备份开发数据库；
仅 Debug 构建可通过 `NOWLY_RESET_DEVELOPMENT_TIME_V32` 指定数据库的准确绝对路径，
执行一次性限定重置：时间/专注设置、闹钟及相关通知、专注记录和旧模块条目。其它数据保留，
Release 构建不会执行此重置。浏览器开发后端独立重置本地存储中的旧时间/专注数据。
