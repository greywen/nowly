# 官网开发与发布

Nowly 官网是独立静态站，定位为“你的 Windows 个人工作桌面”。中文默认，英文位于 `en/`。不包含账号、OAuth 回调、用户数据处理或支付后台，不使用分析脚本、远程字体或第三方嵌入资源。

## 来源与产物

- `website/config.json`：仅公开品牌、正式域名、支持邮箱与发行链接。拒绝未知字段，不能添加审核账号、视频、凭证或 API 密钥。
- `website/content/zh.json` / `en.json`：双语页面内容，渲染时统一 HTML 转义。
- `website/templates/page.html`：公共布局、语言、SEO 与导航。
- `website/assets/site.css`：语义化手写样式。构建从根级 [design.md](../design.md) 提取唯一 Token 清单，不维护另一套颜色和字号。
- `website/assets/screenshots/zh/` / `en/`：八个场景各一套中英文真实应用截图，共 16 张。场景为工作桌面、看板、笔记、世界时钟、专注时段、贴纸、项目推进（日历＋看板＋笔记）和专注学习（四象限＋专注计时＋笔记＋贴纸）。界面及日程、任务、标签、便签、城市和贴纸示例文案按语言分别捕获，不读取用户数据。
- `website/scripts/showcase-scenes.mjs`：捕获和官网构建共用的场景清单、模块布局及双语图片路径。中文和旧中文首页引用中文图，英文首页的首图及全部候选图均引用英文图。
- `website/scripts/showcase-fixtures.mjs`：丰富的双语合成示例数据，包含分类日程、四象限任务、带标签和日期的看板卡片、多条笔记与贴纸。笔记使用内置表情图钉并置顶重点条目；贴纸展示旋转文字、表情及真实图片对象。图片使用仓库 `public/logo.png`，通过隔离模拟后端提供原始字节，捕获前验证图片已解码，不读取用户图片。
- `website/assets/showcase.js`：仅首页加载的本地脚本。中英文及旧中文首页每 5 秒即时切换截图，无滑动或淡入；提供手动选择和暂停／继续，悬停、键盘聚焦、页面隐藏时暂停。减少动态效果模式下默认不自动播放；无 JavaScript 时仍显示首张截图。该限定例外见根级设计规范 §12.6。
- `website/scripts/build.mjs`：构建与内部链接检查，输出 `website/dist/`。
- 桌面应用仍输出根级 `dist/`，Tauri 和 Windows 发布工作流不使用官网目录。

## 命令

在仓库根目录运行：

```powershell
npm run site:test
npm run site:build
npm run site:preview
npm run site:e2e
```

预览地址为 `http://127.0.0.1:4174`，预览前必须构建。浏览器测试自动构建并启动、关闭自己的服务器；运行测试前停止手动启动的同端口预览。测试覆盖双语和兼容页面、图片、键盘、下载链接、390px 窄屏与非必要远程资源。

截图可复现：先启动应用开发服务器，在另一个终端执行：

```powershell
$env:NOWLY_CAPTURE_URL='http://localhost:1420'
npm run site:capture
```

脚本按中文、英文分别捕获八个场景，使用全新浏览器上下文、固定日期和 `Asia/Shanghai` 时区及模拟本机后端，只捕获真实 React 界面。示例日程、任务、便签和贴纸均为合成数据，不展示 OAuth 账号或个人附件；每个场景在模块内容及字体就绪后才保存，失败会标明场景与语言。截图只代表所示模块布局，不代表完整 Windows 壁纸集成演示。

## 页面与兼容

每种语言包含：首页、下载、指南、支持、隐私、条款、数据删除，及日历、任务、笔记、时间、桌面模式、截图、连接与 AI 帮助。

| 路径 | 用途 |
|---|---|
| `/index.html` 及根级页面 | 中文默认网站 |
| `/en/*.html` | 完整英文对应页 |
| `/zh-CN/*.html` | 旧中文 URL 的实际静态兼容页面，canonical 指向根级中文 |
| `/privacy.html`、`/terms.html`、`/data-deletion.html`、`/support.html` | 继续保留旧合规公开路径，现改为中文 |
| `/robots.txt`、`/sitemap.xml` | 索引入口，不包含重复兼容页 |

语言切换保留当前页面，不自动按系统语言重定向。根级以前英文的法律页面现在使用中文；英文版本在 `en/`，发布前应确认平台材料中的语言与 URL。

## 合规资料与产品网站

[app-compliance](../app-compliance/README.md) 保留独立平台权限、审核答案和演示脚本生成器。它不是第二套产品官网。生成的 `review/` 以及本地 `config.json` 含审核字段，**不得部署或加入官网配置**。

可复现的 Google 配置样例随仓库分发；复制样例到本地 `config.json` 后填写实际公开信息和专用审核信息。根级忽略规则保持实际配置、审核输出和网站输出不入库。Microsoft 配置保持预留用途，不能视为已通过平台审核。

## 发布流程

1. 核对公开配置、双语功能描述、支持邮箱、链接和法律政策日期。实质政策变更必须经负责人审核；代码测试不能替代法律审核。
2. 运行官网测试与构建，浏览器检查首页、指南、法律长文和窄屏。
3. 运行合规材料测试；有真实本地配置时生产生成并校验，不能将 `--preview` 占位材料作为正式材料。
4. 备份当前网站，只将 `website/dist/` 的内容部署到现有 HTTPS 域名根目录。不上传整个仓库、审核目录、数据库、截图历史或 OAuth 凭证。
5. 根目录请求映射到 `index.html`；其他页面由实际 `.html` 文件直接访问，不用 SPA 兜底。静态页面不需要 Node 生产服务。
6. 在生产浏览器验证中英文链接、旧 URL、下载、支持和法律页面。确认授权平台中登记域名与 URL 保持一致。
7. 如需回滚，恢复之前的静态目录；网站更新不修改桌面用户数据或应用版本。

官网不内置分析。托管服务可能生成访问日志；负责人应配置合理保留期并核对隐私说明。当前交付只提供源码、产物和步骤，不自动部署、修改 OAuth 控制台或提交审核。

官网动效遵循 `design.md` §12.7：首屏内容和功能卡片首次进入视口时播放 280ms 淡入上移，同组间隔 60ms；精细指针设备的按钮按下反馈为 140ms。减少动态效果时仅保留 140ms 淡入，不使用位移、缩放或错峰。`website/assets/motion.js` 使用 IntersectionObserver，每个元素仅触发一次；无脚本或不支持观察器时直接显示正文。截图轮播仍按 §12.6 即时切换。
官网首页功能卡片与下载按钮使用与应用共源的 Solar outline 单色线性图标（480 Design，CC BY 4.0，https://www.figma.com/community/file/1166831539721848736）。构建时从已生成的应用图标数据生成本地 SVG sprite，随网站离线发布；图标继承文字颜色，作为装饰隐藏于无障碍树，链接文字保持完整。
