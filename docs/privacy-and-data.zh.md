# 隐私与数据

[English](privacy-and-data.en.md) · [用户指南](user-guide.zh.md) · [产品定义与源码依据](product-definition.md)

本文描述当前源码实现，不承诺所有功能离线。本地优先意味着以本地记录为基础；外部日历、AI、更新检查及外部链接都有各自的网络边界。

## 数据存在哪里

| 数据 | 桌面版存储 |
|---|---|
| 本地日程与重复例外、任务与看板元数据、便签、专注记录、时钟、闹钟、布局及多数设置 | Tauri 应用数据目录内的 `nowly.sqlite` |
| 日历连接账户、订阅配置及外部事件缓存 | SQLite；账户/来源标签与事件正文并非整库加密 |
| OAuth access/refresh token、AI API Key | 经 Windows 当前用户 DPAPI 加密的 SQLite BLOB；数据库本身不是全盘加密 |
| 便签、日程、任务等富文本附件 | 应用数据目录 `attachments` 下的文件，数据库保存引用/元数据；既有附件上限为 1 MiB |
| 贴纸图片 | 应用数据目录 `stickers` 下的文件，画布与资源元数据在 SQLite |
| 最终截图 | 系统 `图片\Nowly\Screenshots` 下的 PNG；尊重系统图片目录重定向；SQLite 保存元数据，缩略图缓存独立且可重建 |
| 部分界面偏好 | WebView localStorage，例如模糊程度与欢迎引导状态 |

浏览器开发后端与桌面存储隔离：多数模拟记录使用 localStorage，贴纸作品及图片使用 IndexedDB，富文本附件字节只留在内存。浏览器数据不是桌面的 SQLite，也不具备完整原生功能。

移除贴纸模块只隐藏作品，不删除画布；成功保存作品后清理未引用图片。截图「保存」及「复制图片并完成」都会归档最终输出；记录一直保留到删除。取消截图不产生历史，原始整屏底图只用于当前截图会话。复制会写入 Windows 剪贴板，其它应用可能读取。

## 可选 AI：准确的上下文边界

工作桌面不依赖 AI。需要使用时配置 API 地址、Model ID 和 Key，并选择允许的数据类别。保存/连接会使用模型与凭据，在所配置地址的同一来源上探测协议路径，发送固定 JSON 连接测试，不发送工作区查询结果。远程地址必须 HTTPS，本机 loopback 可以 HTTP。可以配置本机模型服务，但这不证明模型服务本身绝不联网。

普通请求会发送系统指令、电脑当前本地日期时间、设备时区、每周起始日、权限开关、用户输入、最多 12 条近期用户/助手消息，以及修改方案时上一份草稿的动作。消息与草稿不受记录类别开关的内容过滤。不要以为关闭某类别就会脱敏自行输入的内容或已有对话上下文。

模型要求查询时，宿主先检查权限与过滤条件，再把结果加入后续模型请求：

| 权限 | 模型查询结果中的字段 |
|---|---|
| 本地日历 | 记录键、类别、标题、本地来源标签、只读标记；ID/目标及重复实例身份、起止时间、全天标记、提醒偏移、系列 ID |
| 本地任务 | 记录键、类别、标题、本地来源标签、只读标记；ID、优先级、截止日期、完成状态、泳道 ID、视图归属；泳道 ID/名称、默认/完成泳道及视图联动设置 |
| 外部日历（对 AI 只读） | 记录键、类别、标题、订阅/来源名称、只读标记；缓存事件 ID、起止时间、全天标记、来源最后成功同步时间 |

**打开外部日历权限会包含 Google Calendar 的缓存事件**，同时包含 Microsoft 和 ICS 的缓存事件。这是共享开关，不是按供应商/账户选择；仅允许本地日历不会包含外部事件。AI 查询本地外部事件缓存，不直接调用 Google/Microsoft；订阅同步是另一条联网路径。因此，Google 日程缓存可能被发送给用户另外配置的 AI 供应商。

查询适配器不发送本地日程备注、任务描述、外部事件描述/地点、附件或图片字节、便签条目、截图、贴纸、OAuth token 或任意数据库表。这一排除只针对查询结果：用户消息及上一份草稿可能包含日程备注或任务描述。API Key 用来向模型接口鉴权，不作为记录上下文。

日历单次查询为 1–90 天，每次最多返回 200 条并标记截断；一轮请求最多四次模型步骤，序列化上下文上限 192 KiB。这些限制不代表已允许的内容不敏感。

模型只能查询和提出方案，不能直接执行。修改本地日程/任务必须展示方案并由按钮明确确认；即使普通日历编辑器可以远程写入，AI 对外部事件仍然只读。模型没有任意代码、SQL、模块、文件或网络写入工具。方案与范围限定的逆向补丁保存在本地；访问助手存储时清理七天以前的方案。聊天上下文保存在面板内存中，不是持久完整聊天档案。过期或冲突可能阻止确认和撤销。停止请求可阻止未确认的本地写入，不能撤回已经发给供应商的内容；本地方案清理不会改变供应商的数据留存。

可选语音输入使用宿主可用的 Web Speech API，只填写文字草稿，不自动发送。识别可能依赖宿主服务，不能保证离线；不接受该边界时使用键盘输入。

## 日历连接与其它联网

- 基础本地功能不要求 Nowly 账户。Google/Microsoft 账户授权可选，在浏览器中使用 Authorization Code + PKCE（S256）、临时 loopback 回调与 state 校验。Google scope 为 `openid email https://www.googleapis.com/auth/calendar`；Microsoft 为 `openid email offline_access https://graph.microsoft.com/Calendars.ReadWrite`。请求的是日历读写范围，不只是只读；本文不作平台审核/认证状态声明。
- 连接后获取账户供应商/邮箱标签、日历列表和选定日历事件，按需刷新 token。本地外部缓存包含标题、时间、地点、描述和提醒；AI 只发送上表中更窄的字段。
- ICS/webcal 订阅访问指定 feed，webcal 转为 HTTPS。订阅 URL 可能自带访问令牌，分享备份时应当作敏感数据。ICS 只读；最多 50 个来源，刷新间隔 1–30 分钟，界面默认 15 分钟。启动、手动及间隔刷新可在 Nowly 运行时访问已配置来源。失败保留上次成功缓存，内容可能过时。ICS 展开当前月及前后各六个月，OAuth 拉取当前时间前后各约 190 天。
- 普通日历编辑器在账户有写入 scope 时可创建、修改、删除 Google/Microsoft 远程事件，向供应商发送标题、时间、提醒，完整编辑还发送备注/描述。不支持创建/修改远程重复规则。这不同于 AI 的外部只读权限。
- 断开连接通过数据库级联删除本地账户及关联订阅/缓存，不等同于在供应商端撤销授权。如需要，应另到供应商账户设置撤销访问。删除本地订阅不会删除远端日历。
- 启动时的更新检查请求 GitHub 项目最新公开发布信息（`api.github.com/repos/greywen/nowly/releases/latest`），不在请求载荷中上传工作区记录，但 GitHub 会收到常规网络请求信息。请求失败不阻止本地使用。
- 反馈/关于链接可由外部应用打开 HTTPS 或邮件目标，后续处理不在 Nowly 的本地存储边界内。

## 备份与控制

将应用数据目录、截图目录及浏览器/WebView 配置视为个人数据。手动复制前完全退出 Nowly，保留关联文件及 SQLite sidecar 文件，不要只复制单个数据库。数据库单文件不是完整备份。DPAPI 凭据绑定 Windows 用户环境，换环境后重新连接服务，不应把加密 token 当作可移植凭据。上述存储路径不构成自动跨设备备份或完整工作区同步服务。

通过现有编辑器删除记录，通过截图历史确认删除 PNG/缓存，通过日历设置断开来源。调整 AI 权限限制的是未来宿主查询，不会擦除已发送内容或面板内的既有消息；清除 Key 不等同于删除本地方案或在供应商端撤销 Key。远端留存或删除需查阅相应服务设置。
