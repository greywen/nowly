# Nowly 首发宣传包

目标：让 Windows 用户理解“把安排、任务和记录放在同一个可自由布局的工作区”。
依据：当前仓库 README.zh.md、design.md、产品源码与官网演示数据。
不改产品源码；在独立本地端口采集当前 React 界面。演示数据固定于 2026-10-15，不接触个人数据库。

方案：真实产品画面与中文解释。短片用布局原始录屏证明拖动和缩放，中文当前截图补充日常场景。旧录屏明确标注界面演示，不以其证明最新看板行为。
输出：横屏 1920×1080、30fps、约 36 秒；竖屏 1080×1920、30fps、同一叙事重排；6 张 1080×1440 图文页。
声音：保留源录屏无声属性。本轮无授权音乐、不调用付费生成或第三方语音，中文标题承载解释；发布前明确告知无声版。
视觉：白色/暖灰 #F8F6F2；深色正文 #211F1C；青绿 #4FC9DA 仅作强调；字体微软雅黑，实际界面不改造。
所有大字属于宣传字幕而非应用控件。产品截图保留真实比例；不画假按钮、不把局部裁剪表现成真实软件交互。
竖屏主要文字位于 y=168…1330，横向避开右侧动作区。无渐变、玻璃、假性能数字、装饰漂浮和个人隐私数据。

叙事：
1. 0–4 秒：把今天，放在眼前。中文工作区总览。
2. 4–20 秒：桌面按自己的习惯摆。原始布局录屏截取加载完成后的部分。
3. 20–25 秒：先看清下一件事。当前任务与日程截图。
4. 25–30 秒：给专注留一点空间。当前时间/专注截图。
5. 30–36 秒：Nowly · Windows 个人工作桌面；从一个模块开始。Logo 与真实工作区。

发布：抖音竖屏短片；B 站横屏短片；小红书 6 页中文图文。标题、正文、话题分别保存；公开提交前最后确认。
边界：不宣传永久免费、完全离线、跨端同步、团队协作、隐藏的 AI 或滚动截图。说明界面和数据用于演示，实际功能以安装版本为准。
验收：检查无个人资料、无加载画面、中文不裁切、字幕可读、视频时长和编码正确；后台上传成功，发布按钮可用。提交后仍须核查真实状态，审核中不说已上线。
